# 公開準備候補 R1 の範囲

これは隔離ローカルの候補です。GitHub原本はPrivateのままで、push・Public化・リモート履歴の変更はしていません。元の全取得履歴と参照は候補外のPrivate mirror/bundleに保全しています。

## 履歴と原証拠

全取得refsの個人用homeパスを非識別のPUBLIC_USER表記へ一般化しました。相対asset pathとWeb routeは保持しています。内部原本・未確認payload・大量生成物を除外した場合は、採用目的と安全性に応じた選別であり、過去に存在しなかったことにはしません。作者・committerメールは本人判断前に書き換えていません。

過去資料中のSHA/hashは、その時点の原本・実測を指します。個人パス等を一般化した現在の資料bytesが、当時のhashと同一であるという意味ではありません。元→候補のcommit/ref対応と最終候補のhashは、repo外の今回の納品資料に記録しています。過去のFAIL・未実施・Human受入をPASSへ変更していません。

## 公開前の保留

素材の出自記録やAI生成宣言は、入力・契約・第三者素材・再配布条件の確定を代替しません。HOLDの素材は公開承認済みではありません。必要素材を新規制作で置換せず、除外で再現条件が変わるものは人間の判断待ちとしています。Packages・Wiki・取得不能な古いActionsログ、作者メールの公開方針、GitHub側の旧PR参照/cache等は別確認です。公開・リモート更新の承認は、このローカル候補の作成や静的検査とは分けます。
