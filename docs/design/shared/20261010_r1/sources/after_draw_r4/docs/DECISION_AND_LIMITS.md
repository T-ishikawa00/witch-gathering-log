# 決定状態・限界

本件は「希少以上案とコモン入り案の開封後」を対象とし、ホームR3、衣装、家具、全5地域の新規制作には進んでいません。

## 採用する根拠になり得ること

同予算のCでは、同じ確率計算に基づき高品質の比較候補と粉への変換機会を増やせます。初入手・投資・装備・ロック・副効果の違い・共有人数を保護する整理導線と、明示確認後の操作は参照実装で検査できました。

## 正式確定には不足すること

引いた品が実際の最適編成で何個更新されるか、強化がボスの勝率へどう作用するか、購入金額に見合うか、人が何秒かけるかは未確定。品質ごとの数値範囲が未取得なので同品質内の分位だけを比較し、異品質の品を一律に「劣る」として消していません。R6は数値増加でAIが変化する残件もあり、分位優越を戦闘勝利保証と呼びません。

Cは価格と保証も緩和しているため、低レアを混ぜることそのものの因果効果を実証したわけではありません。Aを捨てずに比較対象として保持します。

## 操作見本の境界

固定された9基本型・研成Iの模擬結果です。最初は何も分解せず、まとめ選択と最終確認を必要とします。「全て整理完了」は言いません。高品質や保護品の詳細比較を後で行う必要が残ります。使用する1/2粉、＋0から＋3の30粉、箱容量は完全な本番仕様ではありません。

## 試験の独立性

新参照コードとテストは同じ制作側が作成しています。旧R3の確率処理は原本を直接使い、テストと再計算を行いましたが外部監査済みとは主張しません。契約PASSは面白さや収益性のPASSではありません。乱数は再現用で、実課金の暗号学的安全性は別問題です。

主比較を完了してから、低品質の控えを大量に所持する初期条件の感度を追試しました。その6,000条件は後追いの感度比較として区別しています。99%近い＋3到達は控えを持つケースであり、控えがないと約54%でした。

## 今回変えないもの

4人・完全自動・作戦設定なし・採集と制作・装備の個体性・A案美術を維持します。ガチャで得た衣装や家具を混ぜず、無料と有料で確率を変えず、課金のために自然供給を黙って落とす変更もありません。データや見た目の所有権・返金・購入復元の本番実装を行ったとはしません。
