# R3の変更と未決事項

## 継承
世界R1の50素材・入手先・型ID・親子関係、R2の成長式・33型・69操作の費用を維持。4人完全自動で作戦設定なし。G1とアートR4の内容を変更しない。

## 新しい提案
48時間100%無料、5分1作業、30分1装備、対象通常素材5分1個、既攻略ボス2時間1個、初回固有素材1個、地域別EXP/粉。自然品質の基礎確率を維持し100個保証を追加。既に進化した型の再発見、6個ごとの目標型、出生地域相当の研成。8時間の作業でEXP/粉の1/16の任意補助。15常設課題は本編後に限定。

## 明示的な補足・変更
- G1の24h/15分1装備は技術試作。G2に流用せずR3の新提案として管理。
- 装備由来の供給率倍率は採用しない。安全ルート確認と次地域攻略が戦力の意味。直接DPS連動の経済は別承認が必要。
- 副効果と品質の通常抽選はR2、天井で長期実効確率は変わるので基礎1%と区別。
- 出生時研成は新提案。新規制作初期型は研成I、支払っていない粉の返還は0。
- 進化型の最初の発見はレシピを通す。以後同型の厳選は遺物調査可能。
- 30分の装備枠は開始時の情報を保持。途中の行き先変更は次枠から。通常素材は5分単位で旧作業を完了して切替。
- 自動保存を帰還扱いして48h制限を更新しない。上限は実際の前面復帰／ユーザー操作でのみ再起算。
- 研究課題初回200粉、全15題3000粉は新規の有限報酬案。追加の新素材や新しい戦力上限はない。

## 未確定・未検証
1. 4人AIと10ボスのHP/行動/勝率。資源準備の18.67〜33日をクリア日数と呼ばない。
2. 導入20〜30分の実プレイ。固定EXP920の配分は提案、初回ボス勝利は未証明。
3. 15課題の敵構成と複数解法。元のアニメ契約を無断変更しない。
4. 33型の最終製品ボリュームとしての十分性。装備数増加はR4の美術スコープと別管理。
5. 6.25%の小さな補助と広告省略だけで購入意欲が生まれるか。
6. 端末時計・保存上限・トランザクション・機種変更の製品実装。
7. 完璧な3効果高個体値の自然ドロップは極端に稀。本編要件に使わない。2効果＋1枠再調整を基本に、実プレイで厳選疲れを評価。
8. ゴール自動行程は既解放の入手先に限定。全50源の収集行程は設計と数理比較までで、プレイヤーUIや実装は未完了。

この資料を読むだけで、新規ゲーム実装・大量原画制作・課金SDK追加を承認したことにはしない。
