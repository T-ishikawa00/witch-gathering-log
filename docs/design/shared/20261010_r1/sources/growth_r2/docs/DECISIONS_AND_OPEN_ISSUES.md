## 続けて決める領域

- 4人自動戦闘と10ボスの実数・行動定義・実戦勝率。今回のコードは参照算式のみ。
- 1時間の素材/装備/EXP供給、地域ごとの装備個体研成分布、ドロップ偏り保険、無料/広告/購入差。
- R4の装備29型を最終何型へ広げるか。猫4追加で最終33型と確定しない。
- 本番のDB/バックアップ/機種変更・独立した描画検証。署名/公開/課金権限は別。

## 実装許可

この設計パッケージの作成は、Macの既存プロジェクト編集・ゲーム実装再開・アセット再生成の許可ではない。Humanレビュー後、保存/独立テスト/本体実装を分けて依頼する。
