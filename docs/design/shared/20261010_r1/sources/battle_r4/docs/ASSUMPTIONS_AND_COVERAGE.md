# 検証の境界・補完した仮定

## 1. 根拠

成長R2、経済R3、両パッケージに同梱された世界R1のスナップショットを読みました。`source/` の原本は改変していません。今回のコードは既存G1を実行・変更するものではありません。

|項目|適用・未適用|
|---|---|
|成長・装備能力|R2のactor_stats/item_primary等を直接呼び出し。各装備切り捨ての問題もそのまま再現。|
|素材供給|R3の経済モデルを呼び出し。入り口/深部の確認フラグを別管理し、未来のボス素材は不可。|
|素材費|R2レシピと強化費を支払い。存在しない材料や借金で制作しない。|
|スキル|R01初回攻略に適用される通常・主技能・基礎固有効果のみ。係数、再使用、詠唱・後隙はR2。|
|覚醒・研究上位・進化武器の固有能力|初回攻略では未解放。戦闘モデルへ入力すれば拒否する。全33型・全覚醒の再現ではない。|
|回復と解除|HP回復・結界・添え詠唱を実装。今回の2ボスはslow等を付与しないため、解除一般は未実装。|
|敵|世界R1のID・突進/根連撃/枝打ちという性質を保持。HP等と時刻は今回の比較用候補。|
|導入|R3の合計報酬を得た状態を入力。4課題の通常戦闘・段階配布・所要プレイ時間を再現していない。|
|深部探索|大猪の実勝利後、明示的に初回探索完了fixtureを与える。安全ルートの開放戦は未実装。|
|加入|大猪の実勝利後、帰宅・深部の加入を別取引として処理。既存最高EXPへ一度だけ合わせる。|
|保存|メモリ内の一括状態差替え・操作IDによる二重処理防止。DB・電源断・不正耐性は別問題。|
|速度|表示モードを計算入力に含めない。実レンダー1x/2x/skip・iPhone性能の試験ではない。|

## 2. 新規の仮設定

`data/LOCAL_CANDIDATES.json` が出典です。ボスHP/威力/防護/予告/後隙、通常攻撃の開始と着弾、開始時の主スキル使用可、公開された連撃の合計損失による危機判断、かばう途中の戦闘不能処理、導入固定杖の副効果種類を含みます。

採用済みの事実にしないでください。ボス数値は比較を成立させるために作った候補であり、第三者が用意した難易度テストではありません。試行seedは戦闘乱数を変えるためのもので、同じ100人を観測したデータではありません。

## 3. 公平な比較と限界

守備支援/攻撃寄りは、4個を作る材料総数96、導入の残りを利用して追加72個=6時間の収集という同等予算です。どちらも自然装備は生成して保存しますが、装備への採用・分解は行いません。制作後に得た粉も使わない比較があるため、上手いプレイヤーなら結果が改善する余地を残しています。

12時間条件は6時間の制作準備に加えて6時間の通常収集、24時間条件は同じ装備のまま18時間を追加しています。ゲーム中の進行時刻ではなく「ボス後の計上採集時間」です。敵と戦う秒数、画面を見る時間、未プレイの導入戦は別です。

装備再配分は同じ個体/副効果/EXP/戦闘seedを維持した対照です。ただし、装備者を変えると一部副効果の適性も変わります。「同じHPで配置だけ変えた試験」ではありません。見つけた2配分が最適だとも、全ビルドが成立するとも主張しません。

## 4. 乱数と境界時刻

ターゲット、会心、ガードは独立の決定的ハッシュ系列。経済の装備抽選とも分離。同じ入力とseedなら再現します。整数msの予定イベントを処理し、毒tick→期限切れ→効果コミット→反応→次のAI判断の順。同陣営が常に先行する仕組みではありません。

通常間隔は「次の命中可能時刻を計る」と「次の行動開始可能時刻を計る」の2案を検査しました。完成アニメの長さから暗黙に戦闘速度を決めず、本文を修正して一つに決める必要があります。

## 5. テストとコードの信頼限界

テストと新参照モデルは同じ制作側が作成しました。参照入力と不変条件を確認しますが、独立した別実装との全件一致や外部監査ではありません。新実装の二重受取処理と毒スケジューリングは開発時に問題を見つけて修正し、回帰テストを追加しました。将来のエンジン実装では代表ログと入力を照合してください。

53件のテストには、既存の強化無効段階を「期待通り再現する」テストもあります。そのPASSは望ましい仕様であることを意味しません。

未検証：複数敵一般、敵状態異常、上位覚醒、全装備固有効果、他地域、実UI、全アート、実機、オフライン保存中の電源断、長期継続、課金価値。
