# ゲーム概要・制作判断 R2
2026-10-08 / 次に作るのは「コア試作＋本番品質見本の条件」

## 1. 一文で伝えるゲーム
**アプリを閉じた間に装備が集まり、戻ったら構成を組み替え、その工夫で強敵を突破する。**
主役はキャラの人数でも数値の桁でもなく、「この装備を使うと戦い方が変わる」という判断。

試作では、同じ段階の装備6点を使い、会心・毒・防御反撃と、その混成を比較する。3つの職業に固定するゲームではない。装備ごとの効果を足し合わせるため、毒の武器と防御の靴を同時に使える。

## 2. 今回の決定と、決めていないこと
|区分|扱い|
|---|---|
|維持する方針|iPhone / 2D / 基本無料 / 閉じて進む放置 / 装備ビルド / 高品質 / PvPなし|
|G1用に固定するもの|6枠・固定装備18点・3ボス・計算式・処理順・3探索先・画面4系統・検証用データ|
|試作用の仮説|放置24時間上限、15分1装備、制作素材120、参照用戦闘時間90秒上限|
|製品側の仮説のまま|980円の恒久広告スキップ、広告頻度、長期ドロップ、覚醒、最終コンテンツ数|
|今回は確定しない|正式タイトル、商標、世界観の最終稿、画風、最終エンジン、全ステージ、収益予測|

ここでの「固定」はCodexが試作中に勝手に変えないという意味で、永久に変えられないという意味ではない。

## 3. 目指す感情と、それを作る仕組み
**帰還の期待：** 何か使える装備が増えたか。→探索先ごとに狙える効果を表示する。
**発見：** 数値は低くても役に立ちそう。→戦力一つではなく、発動条件・防御・手数を比較できる。
**納得：** 装備を替えた理由が結果に出た。→戦闘結果に通常・毒・反撃の寄与と生存時間を出す。
**次の目標：** 別の構成も試したい。→地域ごとに装備を集め、素材から狙ったものを作れる。

「進行を苦痛にして広告を見させる」「損失への恐怖で毎日起動させる」「課金しないと勝てない」を中心にしない。

## 4. 実際の一回の流れ
1. 起動時に前回からの探索を精算し、保存完了後に成果を表示する。
2. 新しく意味のある装備を最大3点まで注目枠で見せる。その他を隠して捨てるわけではない。
3. 現在の装備と比較する。攻撃力だけの緑矢印で最適解を決めない。
4. 構成を保存してボスを選ぶ。敵の防御や連撃の特性を事前に読める。
5. 自動戦闘。敗北してもスタミナ・装備・素材を失わない。納得するまで再挑戦できる。
6. 結果を見て装備を直すか、次に狙う探索先を決めて閉じる。

常時画面を開いていないと報酬が減る設計にしない。G1の探索は一定レートで、画面を開いた戦闘が別の装備抽選を無限に増やすこともない。

## 5. G1のプレイモード
### 導入付きコア確認（体験モード）
開始時に会心系6点を所持・装備。最初の番人を倒し、その後、毒と防御を含む試用装備が利用できる。初回の解放は固定報酬と明示し、偶然のレアドロップに見せかけない。

初回目標は、ボスの特性を読み、最低一度装備を変更し、結果の違いを見ること。画面操作のチュートリアルを重ねるより、「比較→変更→再戦」を一回体験できる順序にする。

### バランス検証モード
最初から18点と全ボスを使用可能。基礎能力・レベル・強化額を固定する。これは収集進行のテストではない。

### 放置確認モード
本当の時間経過と、開発用の「8時間分を計算」を完全に区別する。時間送りを使ったセーブには `debugSimulated=true` を記録し、継続率や実機放置の証拠に混ぜない。

G1は装備収集・比較・戦闘をつなぐ試作であり、18点だけで数週間遊べる完成品ではない。

## 6. G1の内容
|構成|内容|
|---|---|
|操作キャラ|1人。技術試作では仮素材。キャラ販売なし|
|装備枠|武器・鎧・手・靴・護符・指輪|

|保存|端末内。購入・進行の復元を将来混同しない構造|

## 7. 長期やり込みの構造案（G1では実装しない）
### 第一段階：構成の核を集める
効果の組合せで攻略を変える。単純な上位レアへの置換だけにしない。
### 第二段階：核を残して周辺を厳選する
同じ核でも、速度・耐久・発動率の配分を変える。ランダム効果を採用する場合、結果の母集団・範囲を先に定める。不要装備は制作素材に戻し、何日も無成果になる状態を抑える。
### 第三段階：覚醒で新しい組み方を作る
「攻撃力が永久に10倍」ではなく、効果の発動条件を変える選択分岐を検討する。例は反撃を一撃にまとめるか、手数へ分散するか。ただし未計算の能力をG1へ混ぜない。
### 第四段階：同じ戦力でも条件が変わる挑戦
敵の特性が変わる挑戦に複数の攻略経路を残す。毎週イベントや無限階層を約束しない。

数週間楽しめるかは長期版の実機・人による確認が必要。今回の3ボスの結果では証明できない。

## 8. 美術の出発点（提案、未承認）
静かなファンタジー遺跡を一人の探索者が巡る。重苦しいホラーではなく、装備の輝きと探索への期待を感じる2Dを検討する。正式名は付けず、作業名は `Idle Loot RPG` とする。

画面上の情報は可読性優先。HTMLの濃いニュートラル色・淡いアクセントはワイヤーの仮テーマであり、正式な絵柄ではない。

## 9. マネタイズは前回の仮説を維持する
初期は無料＋任意広告＋対象広告を恒久スキップする商品1つ。980円は仮価格。G1には広告・決済SDKを入れない。
自動戦闘、基本選別、装備保護、構成保存を有料で解除する設計に変えない。無料で遊ぶ品質と、課金後の快適さを別に評価する。

任意広告の回数・追加素材量は、長期経済がない現時点で確定しない。G2で「広告なし・任意広告利用・スキップ購入」の三条件を比較し、無広告でも装備の核に到達できることを確認する。

## 10. 次の制作判断
G1は進めてよい範囲として提示。G1の結果を見ずに本番素材・全地域・全課金を実装する依頼にはしない。
既存プロジェクトやデータを削除して時間・容量を確保することはしない。追加支払いは未許可。30時間は作業を見直す上限案であり、完成見積りではない。
