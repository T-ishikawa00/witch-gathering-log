# 戦闘・装備仕様 R2.0-G1
正本は `data/content.json` と参照コード `validation/core.py`。
全数値は独自の試作仮説。競合から抜き取った数値でも、最適化済み製品データでもない。

## 1. 時間と乱数
- 時間単位は整数ミリ秒。表示速度とシミュレーション時計は分離。
- 1倍・2倍表示でも同じ入力・seedなら同じ勝敗、時間、発動回数になる。
- 基礎能力と6装備の加算後に上限処理を行う。装備の並び順で結果を変えない。
- PRNGはxorshift32。seed=0は0x6D2B79F5へ置換。32bit符号なし。
- 各通常攻撃で会心用に1回、各敵攻撃でガード用に1回消費。判定は `next() % 10000 < threshold`。
- この乱数はゲーム再現用であり暗号用途ではない。剰余による微小な偏りを含む。必要なら製品版で分布方式を変更しデータ版を分ける。
- seedを見てプレイヤーへ勝ちを保証する説明は禁止。比較は複数seedと別seed群で行う。

## 2. 単位
`*_bp` は1/10,000。500bp=5%。`crit_multiplier_bp=23500` は2.35倍。反撃係数16000bpは防御力の1.6倍。
確率の加算と、倍率をさらに乗算する処理を混同しない。

## 3. 基礎値
HP900 / 攻撃60 / 防御40 / 会心5% / 会心ダメージ1.75倍 / 加速0% / ガード5% / 反撃係数0 / 毒ダメージ0 / 毒持続6秒。
装備を合算後、会心率とガード率はそれぞれ75%で上限。攻撃間隔は `max(400, floor(10,000,000 / (10,000 + haste_bp)))` ミリ秒。

## 4. 通常攻撃
1. 攻撃可能時に会心を抽選。会心は通常攻撃のみに適用。
2. `raw = floor(attack * (crit ? crit_multiplier_bp : 10000) / 10000)`。
3. `damage = max(1, floor(raw * 100 / (100 + enemy_armor)))`。
4. 敵HPへ反映。ログの実ダメージはオーバーキルを除き残HPまで。
5. 毒ダメージ合計が正なら毒を1層追加し、共有期限を延長。
通常攻撃間隔より先に初撃を無料で入れない。初撃は攻撃間隔到達時。

## 5. 毒
装備の `poison_damage` を合算。正なら通常攻撃ごとに1層。最大6層。
1秒ごとの共通tickで `層数 × poison_damage` のダメージ。防御力を無視。会心しない、反撃を誘発しない、追加の毒を付与しない。
ヒット時に、全層共通の失効時刻を現在時刻＋持続時間へ更新。tick時刻が失効時刻と一致した場合は失効を優先してダメージなし。
個別期限を持つ6本の毒ではなく共有期限のモデル。将来変更する場合は明示的に戦闘データ版を変える。

## 6. 敵の攻撃とガード・反撃
敵の攻撃は `cycle_ms` と `hit_offsets_ms` の繰返し。1回ごとにダメージとガードを判定。
激昂後の倍率は `10000 + floor(max(0,t-enrage_start_ms) * enrage_bp_per_second / 1000)`。
先に敵の素ダメージへ倍率を適用して切捨て、その後に防御軽減を適用。
ガード成功時は、軽減後ダメージの45%（55%軽減、切捨て、最低1）を受ける。
被ダメージを処理してHPが0なら反撃しない。
生存してガード成功かつ `counter_bp > 0` なら `floor(armor * counter_bp / 10000)` を反撃の素ダメージとし、敵防御で同じように軽減。
反撃に会心・毒・反撃の再発動はない。連鎖イベントを無限に作らない。

## 7. 同時刻と終了
同時刻は **毒tick → プレイヤー通常攻撃 → 敵の各ヒット**。処理のたび死亡を判定。敵HP0で直ちに勝利。自HP0で直ちに敗北。
G1は90,000ms以内。時間切れは敗北扱いだが `reason=TIME_LIMIT` をUIで区別する（参照結果では勝利false・残HPあり・時間上限で識別）。
戦闘途中の装備変更は無効。編集は次の戦闘から。中断は無報酬で装備画面へ戻れる。

激昂の時刻・上昇幅はJSON参照。番人は24秒から毎秒25ポイント、巨獣は55秒から毎秒16ポイント、衛兵は55秒から毎秒12ポイント、基準倍率100%に線形加算。倍率・時間表示を隠さない。
敵ごとの「毒装備だけ通る」「反撃でないとダメージ0」などの専用無効化は入れない。

## 10. 結果データ
勝敗、理由、経過時間、自HP・敵HP残、通常・毒・反撃の実ダメージ、攻撃回数、会心回数、敵ヒット数、ガード回数、毒tick数を持つ。
`normal+poison+counter = boss_start_hp - boss_remaining_hp` を常に満たす。受けた実ダメージも自HP差分と一致。
DPS表示は分母に今回の経過時間を使う。短い戦闘のDPSと、別の相手への予測DPSを混同しない。

## 11. 既知の限界
純会心が巨獣・衛兵に負ける設定を「すべての会心混成が無効」と説明しない。構成の一部を変えて攻略できるかが重要。
上限に近いガード・高防御が将来支配的になる可能性がある。ランダム効果・レベル・覚醒導入後には同じ検証をやり直す。
