## 保存とQA
全PNGは組込みimagegen由来。元のPNGバイトとC2PAを保持し、変換・切抜き・再圧縮をしていない。プロンプトは `resin_boar_generation_prompts.json`、元出力パス・SHA256・RGBA測定は `resin_boar_asset_metrics.json`。
すべてRGBAでalpha 0を確認。RGBに茶色背景が残るためalphaを無視したビューでは背景が見えるが、調べた外側座標はalpha 0。alpha 1等のごく弱い残留ピクセルが広い範囲にあるため、alpha>0のbboxで自動トリムをしない。alpha>=128のbboxは全身とアイコンが画像内。大猪上下の余白は小さい。半透明フリンジ・フィルタ時の色にじみ・実機合成は未検証。無条件の制作PASSではなく基本原画候補。
旧版2点も `source_variants/` に保存。主要形状を変える前処理はしていない。
