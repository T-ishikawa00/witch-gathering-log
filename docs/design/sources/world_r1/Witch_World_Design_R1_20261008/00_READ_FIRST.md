# 魔女の採集帳 — 世界設計パッケージ R1
2026-10-08 / G2設計提案。現在のG1は変更していません。

## 最初に読む
- `WORLD_BIBLE_R1.html`：背景・魔物・素材・装備・進行を一冊で読む。このHTML単体をMacのSafari等で開けます。正本の参照画像も内蔵しています。ネットワーク通信はしません。
- `docs/01_WORLD_AND_REGIONS_R1.md`：5地域の世界とストーリー。
- `Witch_World_Catalog_R1.xlsx`：比較・検索用の一覧。JSONから生成した閲覧用で、自動同期はしません。

## 内容
5地域、20地図地点、通常魔物20種、ボス10体、素材50種、装備型29例、レシピ29例。数値のない関係設計です。

- `docs/02_BESTIARY_AND_MATERIALS_R1.md`：全30体とドロップ・採取素材。
- `docs/03_EQUIPMENT_AND_PROGRESSION_R1.md`：進化・入手・進行のルール。
- `docs/04_VISUAL_PRODUCTION_BRIEF_R1.md`：承認済み画風を崩さない地域美術の条件。
- `docs/05_INTEGRATION_AND_VALIDATION_R1.md`：拡張・G1との分離・構造検査・未決事項。
- `data/world_catalog.json`：関係表の正本候補。未確定値はnull。
- `data/*.csv`：各表の閲覧用エクスポート。
- `tools/validate_catalog.py`：標準Pythonだけで動く構造検査。
- `qa/structural_validation.json`：実際の検査結果。
- `reference/`：承認済みの4人設定画と、過去G1の資料。元画像・元資料は改変していません。

## 検査
`python3 tools/validate_catalog.py`

構造13項目、異常入力8ケースを確認。戦闘・経済・画面・面白さ・売上の検証ではありません。未確定の確率や必要数を0で補完しないでください。

## 承認と未承認
ユーザー承認済みなのは世界観の核、5地域の方向性、4人の育成・戦闘、キャラクター画像。本パッケージの新しい魔物名・素材・レシピ・加入順は提案R1です。画像内の仮の年齢・名前はプロフィールの確定根拠にしていません。

新しい背景画像、ゲーム用スプライト、実機ビルドは今回作っていません。新規設定の設計と、すべてのアセットの制作は区別してください。

## 実行許可
このパッケージはG2全実装・全アセット量産・外部公開・支払・対外連絡の許可ではありません。ユーザーのMacやプロジェクトを変更していません。
