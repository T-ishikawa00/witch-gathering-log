# 素材・装備・制作量の統合設計 R4

## 1. 元データから変えないこと
50素材、29装備型、29レシピ、20地点、30敵、11ゲート、4主要キャラ。レシピの必要数・確率・敵能力値は元のnull/UNSIMULATED/TUNE_PENDINGのまま。初回報酬の最低1という元資料の個別値も勝手にnullへ変更しない。

素材の見た目を理由に用途や新レシピを追加しない。素材の名称を変えても同じIDを再利用して別物にしない。ゲームデータのcanonical_idと素材画像のasset_idを分離する。

## 2. アセット制作量（ファイル数ではない）
|区分|単位数|含むもの|
|---|---:|---|
|背景基盤|10|各地域FIELD/BOSS、元画像と層とマスク|

G2で159単位を今すぐ制作することは今回の許可範囲ではない。設計が全5地域まであるため、制作方式が固まった後に一括工程へ移せる。

## 3. 装備ビジュアルの扱い
アイコンは全29型の構想を与える。キャラ装着時の外観差分は別工程。承認衣装を29回描き直さず、機能部材最大2つの痕跡を残す。武器の交換で魔女の杖の持ち方や鍛冶師の腕を破綻させないことを後のattachment QAで確認する。

**EQ_S_01はアイコンのみ先行可**。金属槌と木槌の関係は未決。内部木芯案を正解として実装しない。猫には人間用の服・指輪・杖持ちを新設しない。元actor_idsを維持する。

## 5. 収集と制作の演出
野外の採取小物、魔物の素材部位、倉庫の単体アイコン、完成装備の痕跡をつなぐ。世界の雰囲気を保つために全材料を共通粉へ変換しない。完成装備は遺物/旧工房で見つける別の戦利品経路を維持する。

ただし採集小物の手動タップや戦闘の演出再生だけで報酬を増やさない。初回解放と消費素材の保存は別。これは元世界R1の入手/進行契約を美術で崩さないための境界で、ここでセーブや経済コードは変更しない。
