# 正本・変更境界・差異管理 R4

## 位置づけ
本書は全5地域を一つの制作規格へ展開する**追加の美術設計案**。世界R1のID、素材の出自、装備の進化、未確定数値をコピー保存し変更していない。キャラクターの承認済み外見は固定。新規パレット値・表示スケール・パーツ分割は本書の提案で、Human承認やiPhone動作確認の代替にはならない。

## 分野別の優先順位
- キャラクターの姿：`references/APPROVED_CHARACTERS_R1.png`。文字・年齢・仮名をデータにしない。
- 世界・入手順・ID・素材/装備関係：`source_snapshot/world_catalog_R1.json`。原データは`PROPOSED_FOR_REVIEW`を含む。全行を個別Human承認済みと呼ばない。
- 第1地域の詳細：R01 R2仕様、R3制作指示とQA。食い違いは以下の差異表に残す。
- Dots試作：添付5秒動画と会話スクショに基づき、猪の見た目/動きの限定受容を記録。RGBAソース・パーツ・実機記録は未受領。
- 本R4：上記に反しない範囲の制作設計。参考画像をゲーム仕様より上位へ置かない。

## 保全
G1の`src/`、`reports/`、既存`reference/`、セーブを変更しない。新しい4人戦闘の計算と旧G1照合テストは別扱い。本書はゲーム本体を実装しない。

## 証拠の範囲
ZIP3点のCRCを実読検査。世界JSON・森林JSON・承認PNGを原バイトのまま保存。個別hashは`data/source_provenance.json`と`PACKAGE_SHA256.json`。Mac上のファイルはこの環境から参照していない。
