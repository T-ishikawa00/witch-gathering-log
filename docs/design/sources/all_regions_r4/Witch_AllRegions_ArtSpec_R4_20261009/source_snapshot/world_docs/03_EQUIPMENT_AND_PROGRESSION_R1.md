# 装備・進化・進行の接続設計 R1

## 1. 今回変えるのは世界とコンテンツの契約。G1を黙って上書きしない

G1は固定18装備・単体戦・単一の制作素材を使う技術試作。今回の4人、素材50種、装備個体、地域到達は別のG2設計であり、G1の参照式・ID・セーブは保管する。旧ゴールデン28戦や69,984戦の一致で、今回の4人戦のバランスは保証できない。

## 2. 素材だけのゲームへ変えない

装備が出る期待を維持するため、戦利品は二つの出自を持つ。

**素材：** 魔物の部位と採取地点。魔物→性質→装備の因果を持たせる。

**完成装備：** 採集路沿いの旧工房・封じられた保管庫・遺物調査で見つける。装備の抽選は探索の戦利品枠として残し、帰還時には『古い工房で発見』などと出自を示す。獣から人間用の衣服が生えたことにはしない。ゲームを続けるために、毎回手動で遺物箱を開ける必要はない。

どちらの経路も到達フラグとアイテム適格条件を参照する。未撃破ボス後の装備型を入口で抽選しない。一方、制作は狙いの型に届く確定経路として残す。装備の抽選比率と制作に必要な周回数は未決で、今回の設計だけでは収集の面白さは証明していない。

## 3. 装備を四つの軸に分ける

|軸|意味|変えてはいけない混同|
|---|---|---|
|装備型|杖・本・槌・触媒・衣などの役割と進化関係|同じ名前で別の性能定義を上書きしない|
|進化段階|材料で形と得意分野を変える|単なるレアリティ昇格と同一視しない|
|希少度・副効果|同型の個体を厳選する余地|高レアでなければ核の能力が使えない構造にしない|
|強化・研究|投資と新しい選択の解放|装備進化で投資が無説明に消えるようにしない|

29型は上記の『装備型と進化関係』の例。最終版60〜80基本装備・伝説級12種類という旧暫定目標の確定でも、29種類に縮小する決定でもない。

## 4. 装備6枠と4人

人型は既存の武器・身体・手・足・護符・指輪の6枠を基準にする。武器はキャラ適格タグを持つ。魔女は杖、弟子は魔導書、鍛冶師は槌、猫は爪用触媒の例を作った。護符は4人共用の型を用意する。

猫の枠は未確定だったため、**内部は6枠で共有し、表示名と装備可能な型を分ける案**を今回提示する。爪触媒・胴布・前脚飾り・足輪・護符・首飾りなどに対応させる。猫が人間用ブーツを履く処理にはしない。猫専用4枠を独立実装する案へ進める場合は、バランスと保存仕様を再承認する。

承認済みキャラクターの顔・衣装・配色・大きな帽子・黒猫の姿は固定。以下の装備外観は**アイコン、内部装具、武器差分の構想**であり、装備するたびに全身衣装が強制変更されることを意味しない。最初の武器外見も、承認済み設定画を標準外観として保つ。変更スキンを採用する場合は別のビジュアル承認が必要。

## 5. 進化ツリーの代表例

### 魔女の杖：直線成長ではなく二つの研究

若枝の採集杖 → **霧花の毒杖 → 夢庭の呪杖**

若枝の採集杖 → **根守りの結界杖 → 月環の結界杖**

毒の分岐は、胞子を保持する容器、暴走させない菌核、術式を切り替える輪を使う。守りの分岐は、根・枝節の持続性、竜鱗の層、光を封じる硝子を使う。『後の地域の材料だからただ攻撃力が高い』以外の理由を作る。

### 仲間の道具

露灯の手帳 → 水鏡の祈書 → 月綴じの大典。布・膜・綴じ蔓が、回復の保持と支援の連携につながる。

山歩きの木槌 → 響炉の鍛鎚 → 月銀の護鍛鎚。丈夫な木から、熱と共鳴を制御できる槌へ育つ。

灯爪の触媒 → 霧影の爪環 → 夜渡りの爪環。黒猫を人型武器使いにせず、弱体と素早い追撃を触媒の形で表現する。

## 7. 必ず守る進行契約

### 7.1 ボスの素材を、そのボスの初回攻略の必須材料にしない
初回攻略に使う装備候補は、必ず挑戦前の到達フラグ内で作れること。ボス固有素材は撃破後に使う。10体それぞれ2候補を検査したが、入手順の確認であり、戦闘の2解法が実証された意味ではない。

### 7.2 道を開ける情報は永久フラグ
地域到達、仲間加入、レシピの解放、主な物語の進行を、消費する素材の所持数と兼用しない。素材を使い切っても扉が閉じない。初回勝利は『素材受取・フラグ・レシピ解放』をまとめて保存する。

### 7.3 初期地域を無価値にせず、通う義務にも変えない
初期の木材・繊維は新しい分岐の基礎型に使える。進化は既存の親装備を育てるので、初期材料は既にその道具に含まれている。すべての高位レシピに初期素材を何度も重ねて要求しない。

序盤装備の固有機能を後半で使い続けられるかは、別の強化・性能設計が必要。『序盤装備も永遠に最強』は約束せず、役割がある型を育てて残す。

### 7.4 進化で当たり装備を失わせない
進化は別個体の再抽選ではなく、対象個体の型を変える操作。個体ID・ランダム抽選値・ロック・強化投資・保存構成参照を維持する方針とする。副効果が進化先に不適格なら、勝手に消去せず理由と対応を示して停止する。

保存構成が同じ個体を指す場合、変化の影響を事前表示する。実行は素材消費と装備更新を一回の保存単位にする。基礎材料を二重返還しない。分岐の戻し・副効果振り直し・分解還元率はまだ仕様化しておらず、無限増殖がないとの検証は未実施。

### 7.5 時間と報酬を二重利用しない
4人は一つの探索隊として同じ遠征へ参加する。4人だから経過時間を4回精算する処理にしない。通常探索・採取・ボス調査の時間枠を共有し、オフライン分を同じ結果へまとめる。獲得速度の具体式は4人戦の再設計後に決める。

遠征開始時に地域、対象、編成、装備、コンテンツ版を記録する。帰還後に強い装備へ変えて過去8時間の成果まで差し替えない。未撃破の主ボスや新規物語イベントは、オフライン中に勝手に攻略して進めない。既に攻略した範囲の反復だけを精算する。

家の演出と遠征中の編成が矛盾しないよう、遠征の映像は記録・準備表示などの表現を区別する。鍛冶師が前線に出たまま別の身体で常時鍛造するという別生産システムは作らない。

### 7.6 実生活の時間を採取の鍵にしない
月光花・眠り種は、名前に月や眠りがあっても、現実の夜・満月・曜日限定にしない。地域内の魔法環境で常に調査可能。季節イベントだけの素材を、本編の進化必須品にしない。

## 8. まだ追加しない仕組み
自由建築、農園、店舗経営、料理による大量消耗バフ、空腹・寒さゲージ、道具破損、素材の個体品質、装備破壊型強化、仲間ガチャ、ギルド、PvP、日替わりの取り逃し限定素材は、この設計に含めない。

魔女の日常が魅力だからといって、別ジャンルを次々追加しない。採集→戦利品→装備→4人の攻略→新しい採集先という循環を主軸にする。
