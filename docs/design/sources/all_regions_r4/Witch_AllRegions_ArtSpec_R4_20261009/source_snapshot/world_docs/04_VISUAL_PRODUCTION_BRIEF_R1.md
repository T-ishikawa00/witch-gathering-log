# 地域・魔物・素材のビジュアル制作契約 R1

## 1. 正本の優先順位

最上位は承認済み `reference/witch_characters_R1.png`。4人の姿と、下部にある5地域・家の空気感を維持する。本書の文章はその参照を、具体的な背景と素材の因果へ展開する提案。新しいキャラクターデザインの承認取り直しを要求しない。

本資料には**新しい完成背景、ゲーム用スプライト、実機シーンは含まれない**。個々の魔物の名前と形は初稿。綺麗な俯瞰絵だけを作って、素材の形や戦闘での見え方を後から変えることを避けるための制作前仕様。

## 2. 共通の画面文法

キャラクターは精密なドットの輪郭を持たせ、背景は奥行きと柔らかい光を持つ表現を目指す。特定作品のUI・キャラ・マップを複製しない。実ピクセル数、3Dか多層2Dか、ライト数は代表実機見本で決める。

前景には暗めの葉や柱、中景にはキャラクターが立つ読みやすい床、後景には地形と目印。どの地域も戦闘の床面を確保する。iPhone縦画面に4人を表示するため、背景の美しさで予告・HP・対象選択を隠さない。

日常は小さな光とゆっくりした動き。戦闘は行動が起きた場所を短く強調する。常時画面全域の発光、強いブラー、細かい粒子の散乱で『高品質』を演出しない。

## 3. 光と色の役割を分ける

地域の色＝環境の空気。戦闘の色＝効果の区別。アイテム枠の色＝希少度。この三つを混同しない。

例：湿原が紫でも、すべての紫色素材が最高レアということにはしない。森の琥珀樹脂は金色だが、素材アイコンの形とラベルで認識できる。毒は色だけでなく滴・胞子・蓄積マーク、結界は面・弧・割れ、反撃は衝撃の戻る向きで表す。

## 4. キャラクターと世界を結ぶ意匠

月の弧、葉、蔓、真鍮色の留め、採集瓶という少数の共通モチーフを使う。すべての敵に同じ魔法陣を貼り付けるのではなく、森では葉脈、湿原では水の膜、鉱洞では晶線、山では霜の層、古庭では意図的な装飾として展開する。

全身の服を地域色へ塗り替えない。帽子・髪・赤いスカーフなど人物識別の印は維持する。

## 5. 素材→装備の視覚的な因果

|素材|素材の形|装備への使い方|
|---|---|---|
|しなり霊枝|曲がった枝先に乳白色の導管。生木を切らず落枝を選ぶ。|杖の柄の曲がりと導管の発光へ。|
|灯糸|光る結び目のある乳白の糸玉。|手袋・書物・衣の縫い目へ。|
|霧結晶|曇りを封じた短い六角柱。水晶系とは不透明度で区別。|毒杖の霧室と護符の半透明の層へ。|
|水鏡の冠鱗|鏡面の一枚の冠鱗。|祈書の留め具と水鏡状の支援魔法へ。|
|連槌の駆動環|歯ではなく円い駆動環に三つの刻み。|反撃用の関節・魔法の拍子の刻みへ。|
|炉心晶|多面体の橙晶、金属の枠はドロップに含めない。|槌頭の内側に見える橙の炉心へ。|
|月氷の竜鱗|長い氷青の鱗に月の筋。|結界杖の内側の薄膜と月の筋へ。|
|月庭の種核|鹿の器官でなく、金の殻と緑の芽を持つ大きな種。|護符の籠に入った小さな芽と、家に残る鉢へ。|

素材がアイコンに存在するだけで、完成品に一切痕跡がない状態を減らす。一方、使用素材を全てそのまま巨大に貼って、杖が物干し竿のようになることも避ける。主材1つ・機能部材1つを見せ、残りは構造の内側で説明する。

## 6. 魔物の設計画に必ず入れるもの

地域ID・敵ID・通常/中ボス/主ボスの区別、キャラクターに対する大きさ、正面寄り/側面のシルエット、攻撃の予告姿勢、無防備になる姿勢、素材になる部位、戦闘後の回収物を一枚の参照にまとめる。

素材になる部位が存在しないのに鱗や角を落とさない。素材を大きく見せるために生物の構造を不自然にしない。背中に常時生えた宝箱で解決しない。ボスの固有個体と通常種の色違いを混同しない。

## 7. 量産前の確認

まず森の『採集路』『古樹前』の背景系統、通常魔物2種、ボス1体、対応素材・装備の例、4人が同時に立った画面を揃える。森の完全な物量や残り4地域を先に量産しない。

確認するのは、(1) 承認済みキャラと同じ世界に見えるか、(2) 縦画面で行動が読めるか、(3) 素材から装備への因果が見えるか、(4) オフライン報酬画面で欲しいものを認識できるか、(5) 実機で品質・容量・発熱に無理がないか。画像一枚の承認だけを動作確認の代わりにしない。
