# 魔女の採集帳 — 世界・生態・素材設計 R1

> 帰宅したら、家と採集帳に冒険の跡が残る。

**維持する合意：** 魔女の静かな採集・研究生活、4人全員の育成・戦闘、5地域の名称と方向性、承認済みのキャラクター設定画の姿と画風。

**今回の新提案：** 地理、20探索地点、通常魔物20種、ボス10体、素材50種、装備と進化の例29型、加入・進行・入手ルール。地域の名称以外の新固有名、レシピ関係、物量を、既に承認された設定とは扱わない。

**未確定：** 素材の必要数・出現確率、HP・攻撃・回復量、レアリティ比率、所要日数、完成版の最終物量、実機描画仕様。今回のJSONでは該当欄を `null` とする。0や仮の確定値を埋めない。

これは**設定と関係の正本候補**であり、G2の全機能を実装する依頼文ではない。現在のG1、セーブ、既存ファイルを変更しない。

## 1. 世界を統一する五つの柱

### 1.1 世界を救うのではなく、暮らしの中の好奇心
魔物退治は素材を集めるための調査・狩りであり、国を滅ぼす魔王討伐に話を拡大しない。危険な魔物はきちんと脅威にするが、画面全体を恐怖や残酷さで支配しない。最終地域でも、主人公に新たな研究の種と帰宅の理由を残す。

### 1.2 同じ山域と水の流れ
北の白霜の山嶺で生まれた雪解け水が、こだまの鉱洞の鉱床を通り、眠り霧の湿原へ湧き、木漏れ日の森を流れる。魔女の家は森の下流側の乾いた高台。古庭は森の東奥の段丘に隠れる。

つまり、雪・鉱洞・湿原・森林は無関係なテーマパークではない。古庭へは山嶺の観測道で道標を調律してから、森の別の道をたどる。画面上の移動は地図からの探索先選択であり、自由移動オープンワールドを追加する意味ではない。

湿原の毒は胞子溜まりに局在する。流出する水すべてが猛毒、なのに下流の家で普通に飲む、といった矛盾はつくらない。水の詳細な化学をゲーム仕様として扱うわけではない。

### 1.3 同じ歴史と同じ材料文化
過去の魔女たちが採集路、工房、観測塔、庭園をつないでいた。共通する建築は淡い石、木の梁、薄い真鍮色の留め具、丸窓、葉と月の彫刻。森では欠けた意匠、鉱洞では道具の刻印、山嶺では観測器、古庭では整った原型として現れる。

古代文明は巨大なSF工場でも軍事国家でもない。生活と研究のために作られた施設が時間を経て自然と混ざっている。

### 1.4 地域は属性ラベルではなく素材の性質
森は木と繊維のしなり、湿原は液と膜による保持、鉱洞は金属と結晶による伝達、山嶺は冷却と断熱、古庭は保存と接続。素材の性質が、装備の形と能力の理由になる。

『湿原だから毒しか使えない』『鉱洞だからすべて毒無効』にはしない。呪毒は通常の毒液だけでなく、魔力の循環を乱す術式も含むという提案。生物と魔法駆動の構造体に効き方の理由を用意する。具体的な耐性と上限は戦闘モデルで決める。

### 1.5 拠点はメニューであると同時に帰る場所
魔女の家には暖炉、採集机、書棚、錬金机、猫の寝場所を置く。仲間と採集記録が増えることで変化するが、自由建築・農園・店舗経営・村人管理を追加しない。

『家へ戻るたびに別の作業を大量に要求する』のではなく、成果を受け取り、必要な制作をして、次の探索へ出られる場所にする。

仲間の加入前にその人専用の制作を必須にしない。初期の木製道具・布・簡単な触媒は魔女の机で作れる。高位の金属加工は鍛冶師加入後で、必要な鉱石も後の地域に置く。

## 4. 素材を取りすぎて暮らしの世界を壊さない

危険な魔物は調査・狩りの相手にする。ただし、守護樹や月鹿を毎回殺して同じ心臓を集める設定にはしない。通常種・上位種・古い保守装置・固有の守護者を区別し、敵の記録に『回収する部位と再戦の理由』を持たせた。

例：苔冠の生木核は古樹の心臓ではなく、更新された枝の魔力節。月氷の竜鱗は力比べで受け取る古い外鱗。月庭の種核は月鹿の器官ではなく庭で育てられた種。血や解体の演出を足さなくても、採集の手応えを装備と素材の造形で表現する。

この設定のために複雑な生態シミュレーションや資源枯渇システムは追加しない。現実の繁殖時間までゲーム内時計で再現する必要もない。繰り返し遊べることと、キャラクターの暮らしを壊さない説明を両立する。

## 5. 全体のボリュームの扱い

本書は **5地域・20地図地点・通常20種・ボス10体** の関係を設計したもの。20地点は20枚の独立した戦闘背景を意味しない。背景は各地域の入口系／深部系の2組を共有し、小物と照明で地点差を作る案とする。全地域10背景系統と家1系統が見積りの出発点だが、素材枚数・レイヤー数・モーション数の確定値ではない。

素材50種は5地域全体の見通し用。最初から一覧に50種の未発見枠を並べない。森は採取4、通常4、ボス2の10種まで、さらに入口／深部で段階表示する。素材の種類を増やしても、管理操作を増やさない。

G2で実制作するのは、承認後に絞る代表範囲。4人の戦闘と家・森の代表背景・少数の魔物で、望む画風と遊びが同時に成立するかを見る。地域数を埋めるために品質を下げたり、先に全量を発注したりしない。
