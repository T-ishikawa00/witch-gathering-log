# 魔物・素材台帳 R1
**全行が新しい設計提案。背景・素材の因果を固定するための資料で、戦闘数値は未検証。**

## 1. 魔物ごとの見た目・生態・攻略・回収物

各ボスには最低2つの攻略方針を記載した。ただし、この文章は実戦で2構成が勝てる証明ではない。予告は自動戦闘を理解するために表示し、即座の手動回避やジャストガードを追加する意図はない。装備と自動行動方針で備える。


## 木漏れ日の森

### 苔角いのしし — `E_R01_01`

**区分・場所：** normal／こもれびの採集路

**シルエット：** 低い重心、苔の生えた二本の前歯。人の腰ほど。

**生態：** 根を掘る魔獣。採集路へ縄張りを広げた個体を狩る。

**戦闘：** 前脚で土をかいてから前列へ突進。

**対応案：** 予告に合わせるガード構成 ／ 行動前の集中火力と支援

**回収物：** 苔角片（`M_R01_E1`）。折り口が乳白、外側が苔色の湾曲片。 用途：打撃・防御・丈夫な触媒。

**繰り返しの説明：** 戦闘後に欠けた牙の外層を回収。流血・解体の演出はしない。

### 糸灯ぐも — `E_R01_02`

**区分・場所：** normal／こもれびの採集路

**シルエット：** 丸い腹に灯、細い脚は短くまとめ、白い糸巻きが目印。

**生態：** 草食の虫を捕る小型魔物。採集路を覆う巣を払う。

**戦闘：** 糸で一人の手数を落とす。

**対応案：** 弱体解除を使う支援構成 ／ 持続ダメージと複数の攻撃担当

**回収物：** 灯糸（`M_R01_E2`）。光る結び目のある乳白の糸玉。 用途：衣類・手袋・詠唱の保持。

**繰り返しの説明：** 巣と抜け糸を回収する。

### 葉刃むし — `E_R01_03`

**区分・場所：** normal／月白苔の沢

**シルエット：** 背の葉が二枚の弧。脚ではなく葉刃を大きく描く。

**生態：** 魔力を含む葉を擬態する狩食性魔物。

**戦闘：** 短い連撃の後に休む。

**対応案：** ガードと反撃 ／ 回復を置き、休止中へ火力を寄せる

**回収物：** 葉刃殻（`M_R01_E3`）。葉脈のある緑の鎌形殻。 用途：軽量刃・触媒の狙い・機動性。

**繰り返しの説明：** 外殻の欠片を回収する。

### 樹脂ころがし — `E_R01_04`

**区分・場所：** normal／月白苔の沢

**シルエット：** 半透明の丸い琥珀甲殻、短い六脚。

**生態：** 樹脂を固めて身を守る甲虫。

**戦闘：** 甲殻を閉じる間だけ防御が上がる。

**対応案：** 防御が下がる時間の一撃 ／ 長い戦いを支える呪毒と回復

**回収物：** 琥珀の甲片（`M_R01_E4`）。樹脂とは別の薄く湾曲した板。 用途：防具の層・護りの持続。

**繰り返しの説明：** 剥がれた甲殻を回収する。

### 根絡みの大猪 — `B_R01_A`

**区分・場所：** miniboss／根絡みの渡し

**シルエット：** 木の根を冠にした大型の猪。顔と前脚を大きくする。

**生態：** 倒木で帰り道を塞ぐ縄張りの主。

**戦闘：** 土を掻く→突進→疲れて隙。

**繰り返しの説明：** 同種の上位個体を調査対象にする。牙片は一本丸ごとの生体ではない。

**挑戦前に制作可能な候補：** 若枝の採集杖／灯爪の触媒。数量と戦闘勝率を含まない入手順の検証。

### 苔冠の古樹 — `B_R01_B`

**区分・場所：** boss／苔冠の古樹前

**シルエット：** 家より高い古木。胸ではなく枝の結び目に魔力。

**生態：** 古い道標を守る樹の精。採集路に伸びすぎた根を鎮める。

**戦闘：** 細い根の連撃→広い枝の溜め打撃。

**対応案：** 連撃を受け止めて反撃 ／ 結界と回復を保ち呪毒を維持

**回収物：** 苔冠の生木核（`M_R01_BB`）。小さな枝節に白い導管と芽。 用途：木製触媒・持続する護り。

**繰り返しの説明：** 本体を伐採しない。再戦は根の手入れと力比べで、更新枝の節を譲られる。

**挑戦前に制作可能な候補：** 灯糸の採集衣／露灯の手帳。数量と戦闘勝率を含まない入手順の検証。

## 3. 素材ドロップの契約

### 採取・調査討伐
探索時に『今ほしい素材』と入手先を指定できるようにする案。対象作業に成功したときに基礎分を1個以上保証する。具体的な作業時間、基礎量、成功率、追加抽選、装備の出現率は未定。最低1という値はゲーム時間の単価を意味しない。

### ボス
初回勝利は素材の基礎分と解放フラグ・レシピの解放を確定付与する。初回報酬を保存してから表示し、再読込で重複させない。素材を制作へ使っても、進行フラグを消さない。

撃破済みボスの素材は時間を使う調査周回で再入手できる。即時の練習再戦は報酬なしと表示する。練習ボタンの連打・早送り・描画速度で獲得量を増やさない。通常探索とボス調査が同じパーティーの同じ時間を二重に使わない。

### 固有素材と確定経路
ボス素材を『数％を当てないと次の地域へ行けない鍵』にはしない。初回後の必要数と追加抽選は経済設計で調整する。希少性は新しい組み合わせ・見た目・追加性能にも置き、必要素材の抽選地獄だけにしない。

### 素材と装備を区別する
素材は基本的に種類IDでスタックし、個体ごとの品質を持たせない。装備の方だけに個体IDとランダム副効果を持たせる。素材にも品質・鮮度・耐久を同時に追加すると、管理が複雑になるため初期対象外。

図鑑の素材ページには『入手先』『到達条件』『使用レシピ』『所持数』『追跡中の必要数』を同じデータから表示する。未定義素材を文章だけでレシピへ要求しない。基礎素材を減らすために、すべてを名前の違う万能粉へ置換しない。
