# 8アセット制作・書き出し契約 R3

## 全アセット共通
- 完成図は **1画像＝1対象**。図鑑ポスター、表、複数の絵を並べた一覧、装飾フレーム、ラベル文字、ゲームUIを混ぜない。
- 先に単体イラストで造形を確認する。透過・レイヤー・モーションは別工程で品質確認する。
- 日差しの方向、素材の光沢、HD-2Dキャラの輪郭が地域美術と矛盾しない。
- 特定の商用作品に固有の画面やロゴを複写せず、本企画独自の造形と配色を維持する。

## 背景2点
### `BG_R01_FIELD` こもれびの採集路
- 人物・魔物・ボス・UI・テキストなし、1枚の背景景観のみ。
- 森の採集路、左右のシダ、浅い小川、低い木橋、古い月蔓紋の石碑、遠景に魔女の家の屋根。
- 中央下部の歩行床は見通しの良い乾いた小道。4人パーティーの占有幅と攻撃方向を確保。
- 影・法線・透過レイヤー等は描画方式確定時に書き出し仕様を決める。

### `BG_R01_BOSS` 苔冠の古樹前
- 人物・魔物・ボス本体・UI・テキストなし、独立背景。
- 年輪を感じる暗い森と、古い月蔓紋の石碑。石碑は奥の中景に置く。
- プレイフィールドの中央は円形の乾いた広い土。根の範囲予告が読み取れる余白がある。
- 巨大な青い魔石やボス身体の埋め込み、城塞のような人工建造物は不採用。

## 魔物6点
### `E_R01_01` 苔角いのしし
- 斜め前向きの単体フルボディ、背景なし、統一ピクセル密度で描き直す。
- 正本特徴: 低い重心、茶褐色の毛皮、苔を帯びた上向き二本牙。前脚で二度地面を掻き、直線突進する。
- 対応する入手素材: **苔角片**。素材アイコンを別ファイルとして制作する。
- モーション基礎: 待機→攻撃予告→攻撃→後隙、被弾・敗北/鎮静。
