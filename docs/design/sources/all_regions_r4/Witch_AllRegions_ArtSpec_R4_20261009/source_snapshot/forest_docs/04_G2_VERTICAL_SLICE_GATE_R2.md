# G2 森のVertical Slice 制作・受入計画 R2

## 0. 実装の判断点

G1は固定装備18種・3ボス・主人公1人の技術検証。G2の森は同じ計算コードを盲目的に拡張する工程ではなく、4人パーティー、森の敵、アイテムループ、HD-2D風の本番品質という**異なる仮説を検証する工程**。

今回の地域コンセプトアートは、美術の方針提案。**実動作するスプライト・背景レイヤーは未納品**。Mac上のG1を上書きしても完了とは見なさない。

## 1. 制作フェーズ

|工程|作るもの|受け入れの判定|
|---|---|---|
|A 美術の整合|採用4人と同じ縮尺の森の背景サンプル、魔物のキーアート、素材アイコンの一組|森の住人・魔物・素材と一目で認識でき、台帳の形状定義に適合|
|B 表現技術|主人公と黒猫＋通常敵1種の実際に動くシーン|Mac/iPhoneで画面、影、光、ドット密度が破綻しない|
|C 4人戦闘の縦切り|魔女・弟子・鍛冶師・猫、通常2種＋中ボス1体の戦闘基礎|役割分担・攻撃予告・回復・防御・戦闘結果が理解できる|
|D 収集から制作|採集・敵由来の素材、制作、装備変更、放置報酬|同じ素材が採集画面・倉庫・装備説明で一致し、進行不能がない|
|E 地域主ボス|背景 `BG_R01_BOSS` と苔冠の古樹、場面展開|4人の戦術で攻略でき、撃破後に湿原の道が開く|
|F 実機品質|iPhone縦画面、スリープ・復帰、1セッション通しテスト|視認性、フレーム安定、バッテリー・メモリ、保存と復旧に受入不能な欠点がない|

## 2. 視覚と操作の必須評価

1. 4人を並べたとき、魔女の帽子、弟子の小帽子、鍛冶師の槌、黒猫の赤いスカーフが小さくても識別できる。
2. 敵の攻撃予告・対象・範囲が、背景の苔・根・木漏れ日と混ざらず読める。
3. レアリティ表示に環境の琥珀をそのまま流用しない。素材アイコンは「材料の種類と形」で選べる。
4. 戦闘を等速・短縮再生しても、結果ログに誰が何をしたか説明できる。
5. 魔女の家へ帰ったとき、一回の探索成果と次の目標が直感的に分かる。報酬を受け取るまで長い確認ダイアログがない。
6. 装備スプライトを変更しても、正式採用キャラクターデザインの顔・髪・衣装の識別子を失わない。
7. 戦闘・報酬精算・課金前の保存機構の整合が維持される。G1のテストを基準として、新設の4人戦闘は別の参照試験を作成する。

## 3. 最小の本番品質サンプル

**最小セット（G2-B/Cの最初のゲート）**

- `BG_R01_FIELD` の採集路一場面と `BG_R01_BOSS` の木・石碑・床面の構図見本。
- エルナと黒猫、苔角いのししと根絡みの大猪の計4アクターの正しい縮尺と予告を示す動くカット。
- `しなり霊枝`, `露灯草`, `苔角片` の3アイコンと `若枝の採集杖` の1アイコン、素材取得→道具制作がつながる導線。
- 森のBGMの方向性＋採集・魔法・衝突の短いSE。曲の本制作は後でも可。

最小セットが通るまで残りすべてのモンスターや他地域を量産しない。ここは開発の浪費を防ぐための重要なゲート。

## 4. 本番用アセット契約（まだピクセル値はFIXしない）

```
assets/
  backgrounds/R01/field/{source,export,layers}
  backgrounds/R01/boss/{source,export,layers}
  actors/witch/{source,export,anim}
  actors/apprentice/{source,export,anim}
  actors/smith/{source,export,anim}
  actors/familiar/{source,export,anim}
  enemies/R01/<enemy_id>/{concept,source,export,anim}
  items/R01/<material_id>/{source,icon}
  gear/R01/<gear_id>/{concept,source,icon,attachment}
  vfx/R01/{leaf,root,impact,light}
```

制作時はID（例 `M_R01_E1`）をアセット名とメタデータに併記する。背景そのものにUIと敵を焼き込まない。解像度やフレーム数はG2の実機試験で最終決定。

## 5. 決めてからCodexに渡すこと

- 2D/2.5Dの実際のエンジン・レンダラ、Mac上の試作との移植方針
- iPhone縦画面での実際の縮尺とHUD、4人戦闘に必要な行動順・ターゲット指定
- `山歩きの木槌` と承認済み鍛冶師の大型金属槌の関係
- 黒猫の専用装備スロット体系（人型と同じ6枠にするか）
- 素材の必要個数、ドロップ・放置の速度、4人戦闘の敵の強さ
- 実装上のボス再戦で素材を重複取得できないこと、途中保存の整合

## 6. 事業ゲートは別に存在する

Vertical Sliceで「見た目がすばらしい」が成立しても、App Storeで発見されることや980円の永久便利機能が売れることは別。広告・課金の実装は最初の森の美術試作へ混ぜない。市場・検索の評価を別途行い、G3への投資条件にする。
