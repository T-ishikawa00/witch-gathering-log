# R01 採集素材・魔物素材・装備進化 ビジュアル正本候補 R2

## 1. G2の整合ルール

**A. 1素材は形・出自・役割が説明できること。** 宝箱の代用として魔物に無関係な宝石を貼らない。  
**B. 同じ素材でも形が違う:** 採取できる液状の「琥珀樹脂」と、虫の硬質外皮「琥珀の甲片」を混同しない。  
**C. 進化元と強化個体を分ける:** たとえば魔女の杖という装備型、装備個体ID、ランダム副効果、進化分岐、装備強化を別に保持する。  
**D. ゲートと素材を分ける:** 湿原へ進むフラグは初回ボス勝利で記録される。ボス素材を全部消費しても再封鎖されない。  
**E. 必要個数・確率は確定していない:** 原R1の `quantity:null` と `probability:null` を維持し、絵の説明に「3個必要」などと書かない。

## 5. 装備進化の因果とゲーム体験

**魔女の最初の杖:** `EQ_W_01 若枝の採集杖` — 木のしなりと露灯草の安定性で、初心者の魔法を扱いやすくする。  
**森の守り分岐:** `EQ_W_G1 根守りの結界杖` — 中ボスの牙が結界を支え、古樹の更新枝が持続魔力を与える。森の主ボス攻略後の研究・制作目標。  
**次地域:** 同じ杖の別の進化（例：湿原の毒分岐）もG2で比較するが、このR01台帳を破壊的に上書きしない。

**「狩りで装備が出る」楽しさを失わない:** 採取・魔物由来の素材は確実性のある制作ルート。完成装備・ランダムな副効果は森の遺物調査・古工房から発見する別ルート。魔物に完成した人間用ローブをドロップさせない。

## 6. ボス攻略の前提を満たすか

原R1で、根絡みの大猪の事前準備候補は `EQ_W_01`, `EQ_F_01`。苔冠の古樹には `EQ_BODY_01`, `EQ_A_01` が割り当てられている。

材料取得可能性は確認できるが、**その装備なら戦闘に勝てることは未検証**。仲間4人用の戦闘モデルで、回復・防御・毒など複数攻略経路を別途シミュレーションする必要がある。

## 7. アセットの名前づけと連携

IDはゲームデータの参照キーなので、見た目の英語名や画像ファイル名が変わっても元IDを保つ。キーアート、実装スプライト、エフェクトは別識別子にする。

例：`E_R01_01` のデザイン `ART_E_R01_01_TURNAROUND_R2.png`、透過スプライト `SPR_E_R01_01_IDLE.png`、ドロップ材 `ICO_M_R01_E1.png`。まだ制作されていないものはデータ上 `pending` として扱う。
