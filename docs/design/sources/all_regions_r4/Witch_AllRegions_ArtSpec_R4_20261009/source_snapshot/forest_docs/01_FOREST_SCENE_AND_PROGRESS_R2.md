# R01 木漏れ日の森 — 背景・進行・共通美術仕様 R2

## 1. 地域のアイデンティティ

**感情:** 「普段暮らしている森で、まだ知らないものを見つける」。敵は自然に住む生き物であり、すべてが人を襲う悪の軍勢ではない。採集に必要なときに戦い、可能な限り殺戮や解体の描写に依存しない。

**色の階層:** 主環境は苔の深緑、柔らかな若葉色、生成りの石、琥珀の斜光。魔女の衣装は濃紺・紫・真鍮のまま。魔法の状態色やレアリティ色を環境の琥珀色に混同しない。

**共通歴史:** 月と蔓の刻印、淡石の道標、真鍮色の留め、丸い木枠の構造は過去の魔女の採集路の遺産。森だけに突然中世城郭や高度な機械都市を出さない。

**カメラの仮説:** モバイル縦画面を優先する固定斜め視点。環境は深い遠近感があるが、戦闘床面は明瞭で、キャラクターが見えなくなる手前草を置かない。4人＋敵の立ち位置、攻撃予告、HPを実機で確認して画角を確定。

重要: 「4ノード＝完全に異なる描画背景4枚」ではない。共通レイヤーと追加小物の差分で生産性を保つ。ユーザーがノードを切り替えたときは地形と発見物の変化が分かる。

### BG_R01_FIELD：採集路・通常戦闘の画面構成

**後景:** 遠くの山の麓、樹幹の奥行き、家の屋根または採集小屋。  
**中景:** 片側に低い木橋、石の道標、透明な浅い水面。主役が立つ床は明るさを一定に。  
**前景:** 暗めのシダ・苔石は左右と下端に限定し、キャラや戦利品のアイコンを遮らない。  
**採取点:** 「しなり霊枝」は落枝、「露灯草」は半透明の丸葉。採取可能点は輪郭と短い反応で示し、常時強発光させない。  
**時間差分:** 午前の琥珀光を基準に、夕方・雨・夜は演出差分の候補。初期制作では時間帯の大量量産を禁止。

### BG_R01_BOSS：苔冠の古樹前

**ボス本体:** 幹と絡んだ枝は生き物のスプライト側、背後の単なる木々と区別する。ボスを背景へ焼き込まない。  
**後景:** 数百年を感じる暗い森と巨木の輪郭。淡い月蔓紋の石碑を中景中央奥に配置。  
**戦闘床:** 円形の地面。根の範囲攻撃予告を描くため、中央床は葉模様や粒子で埋めない。  
**攻撃時:** 根が地面から押し上がる位置をマーカーで明示。枝の大振りは上方のシルエットと溜め姿勢で予告。  
**決着後:** 落ちた枝節が淡く光り、古樹が静かに枝を引く。伐採・爆散させない。

## 3. 進行・仲間加入の因果

1. **開始:** 魔女と黒猫が拠点から採集へ。森入り口の落枝・露灯草を回収。苔角いのしし・糸灯ぐもを目撃。
2. **中ボス:** 根絡みの大猪の縄張りを鎮める（`G_R01_A`）。渡しを通れるようになり、帰宅イベントで弟子が加入。これ以前に弟子の魔導書制作を必須にしない。
3. **深部:** 月白苔の沢で樹脂・月白苔を入手し、葉刃むし・樹脂ころがしと遭遇。森林素材の別用途を知る。鍛冶師は古樹前の固定進行イベントで加入。
4. **古樹:** 4人で苔冠の古樹を鎮める（`G_R01_B`）。湿原へ続く採集路の解放情報を永続保存。枝核は制作に使い切ってよい。
5. **帰宅:** 採集帳に押し葉。弟子の本と鍛冶師の道具置きが家に増える。ホームそのものを自由建築ゲームにしない。

注意: プロローグ時に魔女の家から出発するので、背景は採集路だけ独立した外国風の旅館や都会の城下町にしない。

## 4. HD-2Dの演出文法（実機検証前の制作方針）

- **レイヤー:** `far / back / playfield / actor-shadow / actors / battle-vfx / front / ui` の責務を分離。背景に敵・操作UI・ドロップ品を描き込まない。
- **ドット品質:** キャラクターと敵のピクセル輪郭の相対密度を揃える。高解像度背景だけに精密な写真テクスチャを貼らない。
- **照明:** 木漏れ日は環境照明、魔法は一時的な局所照明。大技でもHP・対象・攻撃予告の可読性を維持。
- **縮尺:** 主人公の帽子・使い魔の赤いスカーフが識別可能な縮尺を下限にする。敵の素材部位が戦闘スプライトでも伝わること。
- **機器条件:** iPhone縦画面を目標。必要メモリ、レンダリング技術、ピクセルグリッド、同時粒子数はG2実機Vertical Sliceで決定。
