# R05 月隠れの古庭 — 地域別制作仕様 R4

**正本の事実**：world_catalog_R1の名前/場所/素材/レシピを保持。下の構図、配色値、分割、H倍率は追加の制作案。実機未検証。

## 地域の感情と地理
世界を救う終着点ではなく、明日の研究の種を見つける到達点。

森の東奥の高い段丘。空間が折り畳まれた古庭を、山嶺で調律した道標から訪れる。

探索目的：古い魔女の採集記録を読み、栽培と道具づくりの知恵を受け継ぐ。

歴史・造形：R01の蔓月紋の完全形、R02の膜、R03の晶線と金具、R04の月形器が手入れされた庭に集約する。

追加時の分岐：月露の種床の分岐から追加可能。既存本編の門やレシピを書き換えない。

## 色・光・大気
正本色：月白／深藍／熟した金／鈍い薔薇。比較パレット案：#29314D / #EAE5D6 / #B69C63 / #805A6D / #566B57。素材やレアリティの色を意味しない。

主光：上方の月白と研究小屋の控えた暖色。足元は深藍に沈めず、月銀の形が見える反射。

空気：光を溜めた硝子、静かな花弁、少ない月塵。遠い宇宙や惑星を配置しない。

音の方向案：葉と硝子の細い響き、最後は家へつながる暖かな静けさ。荘厳な世界救済音楽を前提にしない案。

禁止：宇宙・天界への舞台転換／月鹿の角・心臓ドロップ／夜咲き花獣の鹿化／ランタンに黒猫の顔を足す。

BOSS：庭の円い芝土場、背後に魔女の家と呼応する小さな研究小屋。月鹿と芽吹きの波は別素材。
