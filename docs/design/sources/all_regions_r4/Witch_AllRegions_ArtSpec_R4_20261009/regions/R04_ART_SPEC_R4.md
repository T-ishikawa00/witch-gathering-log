# R04 白霜の山嶺 — 地域別制作仕様 R4

**正本の事実**：world_catalog_R1の名前/場所/素材/レシピを保持。下の構図、配色値、分割、H倍率は追加の制作案。実機未検証。

## 地域の感情と地理
厳しい山だが、見晴らしと静けさがご褒美になる。

鉱洞の上層出口から登る北の稜線。雪解け水が鉱床を通り、湿原と森へ戻る。

探索目的：寒い場所でも魔力を安定させる素材と、古庭へ向く観測道を探す。

歴史・造形：風で磨かれた黒岩、吹きだまりの丸い面、円窓の観測塔、月形観測器。山脈を別大陸にしない。

追加時の分岐：風編みの観測塔の分岐から追加可能。既存本編の門やレシピを書き換えない。

## 色・光・大気
正本色：雪の生成り／氷青／遠景の藍／小さな朱。比較パレット案：#E5E1D9 / #9DBFCF / #4B5F7E / #4A4D53 / #9B4B45。素材やレアリティの色を意味しない。

主光：左上から低温の白い光、影は藍。朱の山道布と雪灯草の芯だけ小さく暖色を置く。

空気：低密度の雪粒・地表を流れる薄い雪煙。予告中は手前雪を抑制する。

音の方向案：遠い風と乾いた氷。狼追撃と竜の吸気を環境から分離する案。

禁止：白一色の白飛び／常時吹雪でHPを隠す／寒さゲージ・防寒消耗品の新設／白角獣を二本角の鹿へ変更。

## 2系統の背景と4地点
FIELD：足跡の読める雪道と黒い露岩。白角の稜線・塔前は床と目印の差分。端の崖は装飾で落下操作を要求しない。

BOSS：広い岩棚と遠い谷。山竜の頭・胸・翼の予告域を右上に確保。翼や尾を地形として焼き込まない。

層と座標は共通規格に従う。地点の切替は戦闘床と目印で分かるようにし、勝手に新しい採取物を描かない。
