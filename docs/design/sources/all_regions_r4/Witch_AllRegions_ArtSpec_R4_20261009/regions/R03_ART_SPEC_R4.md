# R03 こだまの鉱洞 — 地域別制作仕様 R4

**正本の事実**：world_catalog_R1の名前/場所/素材/レシピを保持。下の構図、配色値、分割、H倍率は追加の制作案。実機未検証。

## 地域の感情と地理
機械工場ではなく、昔の魔女と職人が協働した採掘場。

湿原の上流側の斜面に入口。上層坑道が山道につながり、地下水は湿原へ下る。

探索目的：アイラと、魔法を通す金属と熱を留める炉心晶を探す。

歴史・造形：手掘りの石段、低い補強梁、革帯、銅留め、同心の晶線。自然洞窟が主、工具は付属。

追加時の分岐：雲母の地下湖の分岐から追加可能。既存本編の門やレシピを書き換えない。

## 色・光・大気
正本色：青紫の水晶／暖かな銅／灰銀の岩。比較パレット案：#282E3E / #695D8E / #A5A0AA / #B07B4B / #E4BE75。素材やレアリティの色を意味しない。

主光：青紫の晶洞光と小さな橙の炉光。主役の正面は暗く沈めず、熱い光は炉口一か所に限定。

空気：奥の薄い粉塵と水の少数滴。鉱石の常時明滅は避ける。鎚の衝撃粉は戦闘VFXで独立。

音の方向案：短い鉱石の共鳴と遠い滴。環境の残響を長くしすぎず、三槌の拍子が分かる案。

禁止：工業都市・現代配線／どの岩にも紫宝石を貼る／敵を背景の機械へ焼き込む／金属敵は呪毒完全無効という美術側の決定。

## 2系統の背景と4地点
FIELD：灰銀の壁と工具跡の残る坑口床。中景の柱状晶、橋差分と黒い地下湖差分を差し替える。

BOSS：古い炉を奥に置いた広い岩床。炉守りの本体も腹の熱も背景とは分離。床の熱予告を読ませる暗めの平面。
