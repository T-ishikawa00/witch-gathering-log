# R01 木漏れ日の森 — 地域別制作仕様 R4

**正本の事実**：world_catalog_R1の名前/場所/素材/レシピを保持。下の構図、配色値、分割、H倍率は追加の制作案。実機未検証。

## 地域の感情と地理
普通の森に見えて、研究の種があちこちにある。

家の南東に広がる低山の森。湿原から流れ出した小川が家の近くを通る。

探索目的：薬草の下処理に使う樹脂を探し、古い採集路を整える。

歴史・造形：丸い根のアーチ・低い木柵・小さな月蔓道標。苔の短い縁と落葉を端へ集める。

追加時の分岐：月白苔の沢の分岐から追加可能。既存本編の門やレシピを書き換えない。

## 色・光・大気
正本色：琥珀色の木漏れ日／苔の緑／生成りの石。比較パレット案：#253F36 / #71864C / #D6BA70 / #EFE2C5 / #584B39。素材やレアリティの色を意味しない。

主光：左上から琥珀の柔らかな斜光。樹冠の隙間のみ高輝度、戦闘床は中明度を保つ。

空気：葉影の遅い揺れ、少数の落葉、浅水の細い反射。常時火の粉や強い発光粒を置かない。

音の方向案：乾いた葉擦れと近い小川。戦闘予告音が出るときは環境音を控えめにする案。

禁止：巨大神殿・城塞／古樹胸部の青い巨大宝石／露灯草を鈴形の花へ置換／樹脂を炎属性の結晶へ変換。

BOSS：石碑を背にした円形の土場。後方は普通の森。苔冠の古樹の幹・枝・根・発光節は一切背景へ描かず別アクター。
