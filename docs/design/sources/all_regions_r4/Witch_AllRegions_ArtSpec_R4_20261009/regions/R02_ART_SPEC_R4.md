# R02 眠り霧の湿原 — 地域別制作仕様 R4

**正本の事実**：world_catalog_R1の名前/場所/素材/レシピを保持。下の構図、配色値、分割、H倍率は追加の制作案。実機未検証。

## 地域の感情と地理
怖い毒沼ではなく、美しいが扱いを誤ると危うい温室。

森の北側、鉱洞の湧水がたまる浅い盆地。毒性は胞子溜まりに局在し、流出口の苔床で薄まる。

探索目的：月光花を求め、眠り胞子の性質と霧を留める結晶を調べる。

歴史・造形：R01と同じ丸木・真鍮の留め、細い葦束、根のアーチ、平らな菌傘。曲線が主で鋭い岩山にしない。

追加時の分岐：月光花の水辺の分岐から追加可能。既存本編の門やレシピを書き換えない。

## 色・光・大気
正本色：青緑の霧／薄紫の花／淡い月白。比較パレット案：#233E48 / #5A8D8A / #A7A1BE / #E9E7DA / #81745D。素材やレアリティの色を意味しない。

主光：発光植物の冷白光が霧を通って柔らかく広がる。A_R02_01の採集灯のみ小さな暖色補助とする整合案（CF10）。

空気：背の低い霧帯と大きくゆっくりした水紋。透明魔物の輪郭を背景反射から分ける。

音の方向案：小さな水滴、葦の擦れ。胞子は柔らかい息、反射は短い澄んだ音として区別する案。

禁止：毒液が全景を覆う終末沼／全面ネオン紫／現実の夜しか採れない描写／水面とくらげの輪郭の同化。

## 2系統の背景と4地点
FIELD：葦の間を通る木道と乾いた広い退避床。浅い水は背景側へ流し、足が水没して見えない構図は禁止。

BOSS：大根のアーチに囲まれた入江。手前に連続した土と板の乾いた戦闘床、水鏡は奥。大蜥蜴・その反射は独立。

層と座標は共通規格に従う。地点の切替は戦闘床と目印で分かるようにし、勝手に新しい採取物を描かない。
