# R01 個別美術・差異QA R3

最上位は承認済みキャラおよび地域設計。以下は **生成コンセプト絵の差異** であり、仕様変更ではありません。

## BG_R01_FIELD こもれびの採集路
- **設計で守る特徴:** 森の琥珀色の斜光、採集路と浅い小川、低い石橋。最終構図では魔女の家の遠景屋根と、左右のシダ、中央の見通しのよいプレイフィールドが必須。
- **ドロップ:** 対象外
- **今の画像が未完成な理由:**
  - 参照切り出しでは遠景の魔女の家が判別しづらい
  - スマホ縦構図・中央の4人＋敵の配置余白は未検証
  - 多層パララックス素材、プレイフィールドの地面マスクは未作成

## BG_R01_BOSS 苔冠の古樹前
- **設計で守る特徴:** 巨樹の輪郭、月と蔓の刻印がある古い石碑、石段、広い乾いた円形の戦闘床面。ボス本体は背景に焼き込まない。
- **ドロップ:** 対象外
- **今の画像が未完成な理由:**
  - 参照では樹木の発光部分が大きく青く、既存仕様の小さな白い枝節と食い違う
  - 本来分離するべき古樹本体が背景に融合している
  - 中央戦闘床の広さ、予告マーカーの見やすさが未保証

## E_R01_01 苔角いのしし
- **設計で守る特徴:** 低い重心、茶褐色の毛皮、苔を帯びた上向き二本牙。前脚で二度地面を掻き、直線突進する。
- **ドロップ:** 苔角片
- **今の画像が未完成な理由:**
  - 牙が上向きの二本だと十分に読める最終輪郭が未確定
  - 乳白色の欠け目の表示・素材破片アイコンを個別制作する必要がある

## E_R01_02 糸灯ぐも
- **設計で守る特徴:** 丸い胴、8脚、腹部の淡黄色の灯器官、腹の下の白い糸巻き。攻撃は光る糸による速度低下。
- **ドロップ:** 灯糸
- **今の画像が未完成な理由:**
  - 発光が強く巨大な魔石と誤認されやすい
  - 白い糸巻き・抜け糸と発光する節の独立素材絵がまだ無い

## E_R01_03 葉刃むし
- **設計で守る特徴:** 左右に大きく外反した二枚の鎌形葉と小さな虫体。葉刃を開いて予告し左右連撃を放つ。
- **ドロップ:** 葉刃殻
- **今の画像が未完成な理由:**
  - 葉の形が通常の葉翼に見える可能性がある
  - 葉脈つき硬質断面を見せる必要がある

## E_R01_04 樹脂ころがし
- **設計で守る特徴:** 球に近い六脚甲虫、琥珀樹脂が固まった半透明の甲殻。防御姿勢から短く体当たり。
- **ドロップ:** 琥珀の甲片
- **今の画像が未完成な理由:**
  - 甲殻が炎・火属性の怪物に見えないよう明度と発光を抑える
  - 「琥珀樹脂」と「琥珀の甲片」は異なる素材であることを表示する

## B_R01_A 根絡みの大猪
- **設計で守る特徴:** 通常個体より大きく、額から後頭に根を巻き付けた巨大猪。地面を掻いて突進予告、後隙で反撃を許す。
- **ドロップ:** 根絡みの牙
- **今の画像が未完成な理由:**
  - 相対縮尺、突進の方向を示す床マーカー、攻撃前・後隙の姿勢差分が必要
  - 素材は牙丸ごとではなく年輪模様の硬質片

## B_R01_B 苔冠の古樹
- **設計で守る特徴:** 家より大きな古樹。低い幹分岐と太い樹冠、幹の小さな白い枝節。細根の連撃と大枝の大振りが分かる予告姿勢。
- **ドロップ:** 苔冠の生木核
- **今の画像が未完成な理由:**
  - 参照画像では青い巨大宝石と寺院風構造が強調されており正本の生態デザインと不一致
  - これは生きた樹木のゲーム用独立スプライトではない
  - 素材の生木核は心臓ではなく更新した枝節であり、討伐して消滅させない

## 制作の次の順序
1. `BG_R01_FIELD` だけを本当に単独の描き下ろし背景として制作し、UIや人物を入れずに実機で構図を試す。
2. `BG_R01_BOSS` をボスが描かれない空の戦闘場として制作し、古樹本体を別のアニメート可能な敵素材に分ける。
3. `E_R01_01` と `E_R01_02` の2体について三方向・攻撃予告・素材を完成させ、ピクセルグリッドと縮尺の基準を確立する。
4. 残る2通常敵と2ボスに同じ基準を展開する。
5. 4人パーティーと敵を同一iPhone縦画面に重ね、文字サイズ・エフェクト・発熱を評価する。
