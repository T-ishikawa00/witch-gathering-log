# 変更管理・未決事項・原資料との優先順位 R2

## Source-of-truth

1. ユーザーが承認した`witch_characters_R1.png`の4人の容姿・服飾・配色。
2. `Witch_World_Design_R1_20261008` 内の正式なキー（地域、探索地点、敵、素材、装備ID、必要素材の参照）。これは**前回の提案設計を固定参照するための基準**であり、R1新設定が全てHuman承認済みという意味ではない。
3. 今回R2のモーション・背景構成・アイコン形状の詳細案。元R1を無断改変しない追加仕様。
4. 参考コンセプト画像。**画像に書かれた名前・素材・個数・服の細部はR1/R2文章と矛盾すれば採用しない**。

## 監査で見つかった主なリスク

### 1. アイラの槌（要確認）

承認したキャラ絵の鍛冶師は重厚な金属製の大槌を担いでいる。一方、R1の森で作る初期武器 `EQ_S_01` は `山歩きの木槌`。**これは目視上の不一致リスク**。解決案は、キャラ固定の工房用槌は持参した既製品とし、森で作る品は戦闘性能を補う木芯・樹脂・甲片の交換部品として表現する方法。別案はIDを保持しアイテムの表示名を「山歩きの鍛鎚」に変更すること。ユーザー承認なしに名称変更しない。

### 2. G1の1人用戦闘とG2の4人パーティー（実装変更）

G1戦闘計算の28戦照合・6枠を、そのまま4キャラ全員へ適用するのは危険。G2では行動順、回復、盾役、敵の範囲予告、サポートの重複、キャラ個別装備枠について新規モデルとテストが必要。

### 3. 森の中ボスを倒した後の解禁順（参照上整合）

開始時に入手できるものは `しなり霊枝`, `露灯草`, `苔角片`, `灯糸`。`琥珀樹脂`, `月白苔`, `葉刃殻`, `琥珀の甲片` は中ボスクリア後。`根絡みの牙` は中ボス後、`苔冠の生木核` は主ボス後。素材の解禁より早く必要なレシピを登場させない。

### 4. 古樹と大猪の再戦資源

連続の即再戦を無料で押し続けて素材を無限獲得する仕組みは禁止。R1では「報酬付き再戦は探索時間枠を共有」とされる。素材は部位の更新や枝節の譲渡として扱い、キャラが残酷な解体を繰り返す描写にはしない。

### 5. Pixel art とライティングの不一致

ドットの相対密度がバラバラ、魔法VFXだけ非ドットの解像度で強く光り過ぎる、3D背景の金属質感がキャラクターよりリアルになりすぎるケースがあり得る。HD-2Dという言葉を仕様にするのでなく、**実機のゲーム画面一枚**でガイドを確定させる。

### 6. 自前集客・販売の未解決

第1地域の美術を完璧にしても、自然流入や課金転換は検証済みにならない。G2制作工数を市場検証と切り離して制御する。

## 人間が判断するときの基準

画像が気に入っただけで資産が製品化されたとはみなさない。`森の景色に帰りたくなる`、`敵の攻撃が読める`、`ドロップの理由が分かる`、`手に入れた材料で作りたい装備が想像できる`、`承認済み4人を小さい画面でも識別できる`を順に評価する。
