# R01 魔物・ボス美術設計 R2 — 4通常＋2ボス

このページは前回の魔物IDとドロップ定義を維持し、シルエット・素材部位・戦闘の予告・勝利時表現を具体化する提案。ゲーム内の攻撃ダメージ・時間は未確定であり、モーションの採用＝戦闘バランスの承認ではない。

## 共通のモンスター制作契約

- 同じ山域の苔・木質・琥珀の素材感。どの敵にも無関係な宝石や金属をくっつけない。
- スプライトでの第一識別子は**輪郭**。色だけに頼らない。
- 採取可能な素材は、ボス図鑑の説明とアイコンで一貫して示す。
- 「予告姿勢→攻撃の軌跡→硬直/隙」の3状態を明示。HP数値を増やすだけの強敵にしない。
- 通常敵の立ち絵は斜め前向き、必要に応じて裏・横を追加。HD-2Dの相対ピクセル密度は魔女の試作結果で確定。
- 捕獲・払い落とし・更新した体表組織の採取など、毎回の戦利品に納得できる説明を持たせる。解体の血生臭さは描かない。

## 01 苔角いのしし `E_R01_01`

**役割:** 最初の「攻撃を見て備える」を教える敵。 **出現:** `A_R01_01`。 **入手:** `M_R01_E1 苔角片`。

**シルエット:** 地面に近い重心、幅広い首、二本の上向きに湾曲した苔色の前牙。魔女の腰ほどの高さ。大型ボスと異なり、枝が頭から生えた巨大な冠にはしない。

**色:** 暗褐色の毛、抑えた苔緑、牙の欠けた部分は乳白色。森の床と重ならないよう腹部・目に明度差。

**通常:** 四肢で小刻みに地面を探る。 **予告:** 前脚で土を二度掻き、牙を横へ傾ける。 **攻撃:** 直線突進。 **隙:** 前脚を踏み替え、頭を振る短い後隙。

**ドロップが出る理由:** 突進と木への擦れで、牙の硬質外皮が剥がれ落ちる。アイコンは曲がった苔色の薄い破片で、乳白の割れ目を見せる。

**使用先:** `根道のブーツ` の滑り止め・姿勢保持。後の防御系装具でも角の制動性を参照可能。

## 02 糸灯ぐも `E_R01_02`

**役割:** 行動妨害と弱体解除の理解。 **出現:** `A_R01_01`。 **入手:** `M_R01_E2 灯糸`。

**シルエット:** 小ぶりな丸い胴、細長すぎない脚8本。腹に温かな淡黄色の灯器官、腹の下に白い糸巻き。大きすぎる青い魔石にはしない。

**通常:** 一か所で薄く揺れる糸を整える。 **予告:** 糸口が光り、狙った仲間へ細い線が伸びる。 **攻撃:** 対象1人の攻撃テンポを鈍らせる糸。 **隙:** 腹の光が弱くなり一時的に身を縮める。

**ドロップが出る理由:** 払い落とした巣の、光る節を持つ抜け糸。アイコンは白い糸玉に一つの光る結び目。クモ本体の器官を抜き取らない。

**使用先:** 露灯の手帳の綴じ、灯糸の採集衣の縫い糸、灯糸の作業手袋、露苔のお守り、黒猫の灯爪の触媒。

## 03 葉刃むし `E_R01_03`

**役割:** 多段攻撃に備え、攻撃後の隙を突く。 **出現:** `A_R01_03`（中ボス勝利後）。 **入手:** `M_R01_E3 葉刃殻`。

**シルエット:** やや低い昆虫体に、背の左右へ大きく外反する二枚の鎌形葉。脚や頭より弧状の葉刃を先に認識させる。

**通常:** 木の葉のように静止し、風に合わせて小さく振れる。 **予告:** 葉刃の縁が立ち、左右に開く。 **攻撃:** 左右の短い連続斬り。 **隙:** 葉を折り畳み、殻を冷ます。

**ドロップが出る理由:** 薄い鎌状外殻が脱皮の際に落ちる。アイコンは葉脈が通った緑の鎌形殻。普通の広葉樹の葉と違い、硬い断面を描く。

**使用先:** 灯糸の作業手袋の手の甲の薄板、葉結びの指環の精密な狙いの導片。

## 04 樹脂ころがし `E_R01_04`

**役割:** 防御する敵の開き時を見極める。 **出現:** `A_R01_03`。 **入手:** `M_R01_E4 琥珀の甲片`。

**シルエット:** 球に近い短い六脚の甲虫。大きく湾曲した半透明の甲殻は琥珀樹脂が硬化したもの。火球の怪物に見える常時炎は付けない。

**通常:** 樹脂塊を押すように歩く。 **予告:** 琥珀甲殻を閉じて防御姿勢。 **攻撃:** 甲殻を開く瞬間に短い体当たり。 **隙:** 脱力して薄い腹部を見せる。

**ドロップが出る理由:** 甲殻外層が更新・剥離した板状片。**「琥珀樹脂」そのものとは別素材**で、薄く湾曲した甲片アイコンを持つ。

**使用先:** `山歩きの木槌` の軽い帯状補強など、衝撃を分散する装具。

## 05 根絡みの大猪 `B_R01_A`（中ボス）

**役割:** 第1の攻略壁。 **出現:** `A_R01_02`。 **入手:** `M_R01_BA 根絡みの牙`。 **勝利ゲート:** `G_R01_A`。

**シルエット:** 一般個体より幅広く大きな猪。木の根が冠のように額から後頭へ巻き付く。巨体で低い角度から突進するため、顔・前脚・牙を大きく描く。

**環境:** 小川の根の橋を自分の縄張りにする。プレイヤー4人を横幅に並べて叩き潰すのではなく、前列への攻撃方向を予告する。

**行動:** 地面を掻く（予告）→高威力の突進→荒く息をつく（反撃チャンス）。予告は画面床面に線を表示して、背景の根と区別。対抗経路は防御して隙を待つ・溜め前に集中攻撃するの少なくとも二つ。

**ドロップ:** 牙丸ごとではなく、擦れて外れた年輪模様のある大きな硬質片。景観と生き物の継続を壊さない採取表現。

**制作注意:** 大猪を倒すために大猪由来の牙が必須であってはならない。後の「根守りの結界杖」の材料だが、主ボス攻略後のアイテムであることを維持。

## 06 苔冠の古樹 `B_R01_B`（地域ボス）

**役割:** 森を研究してきた集大成。 **出現:** `A_R01_04`。 **入手:** `M_R01_BB 苔冠の生木核`。 **勝利ゲート:** `G_R01_B`。

**シルエット:** 家より大きな古木。低い幹の分岐、太い樹冠、幹の節に小さな白い光。顔を巨大な髑髏にする必要はなく、年輪・根で生き物としての表情を作る。

**位置:** 背景には普通の大木があるが、古樹の根・枝はボスの独立描画。背後の石碑と絡めつつ、当たり判定用の葉・枝の構造を分離する。

**行動:** 複数の細根が伸びる予告→連撃→大枝が高くしなる予告→広い攻撃→魔力が落ち着く隙。対策は反撃・結界と回復を維持した持続攻撃など複数。

**ドロップの倫理と因果:** ボスの心臓・魂を引き剥がさない。戦闘後、根が静まり、更新した枝節（白い導管が見える小核）を受け取る。「苔冠の生木核」という名前に対応するが、本体の死亡演出はしない。

**制作注意:** 古樹を倒して湿原が解放されたという記録は消費素材と別。再戦は道標の手入れや模擬の力比べとして成立させる。

## 魔物の制作単位と納品の具体例
