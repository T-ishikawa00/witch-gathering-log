## 重要な区別

**採用済み:** 4人のキャラクターの姿・5地域名・「採集→素材→装備→探索」の方向性。  
**今回の設計提案:** 森のロケーション詳細、魔物の形状・行動予告、部位・素材の制作規則、画面構図。  
**今回できていない:** 背景だけの完成一枚絵、モンスター透過スプライト、実動作アニメーション、iOS実機データ。  
**未確定数値:** ドロップ率、レシピ数量、戦闘HP、動作速度、最終スプライトピクセル規格。

上記の未確定値は推測で固定しない。コンセプトボードは良質な方向性確認に使うが、画像中の文字・素材名・ボス名は元データより優先しない。
