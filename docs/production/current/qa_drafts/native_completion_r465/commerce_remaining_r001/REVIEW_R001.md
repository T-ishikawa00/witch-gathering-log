# Commerce boundary review (R461/R463)

**Conclusion:** I found no concrete defect in the bounded local receipt/replay path that justifies another mock adapter or test harness. The material remaining gap is production authority integration: the normal app deliberately exposes no real purchase path, and the Python authority deliberately cannot authorize production. Enabling that requires an external trusted-service/product decision and Apple account configuration; a client-only network stub would add no meaningful evidence.

## Remaining work classification

**Locally verified:** deterministic ledger business rules, mock purchase/revocation, signed synthetic Sandbox rehearsal, receipt-to-save import, idempotent/cold behavior, and cross-process persistence as scoped above.

**Production code/integration absent, but blocked on an external contract:** `authority.py` explicitly has no HTTP listener, Apple JWS verifier, production RNG, StoreKit production wiring, or live catalog (lines 3-5); `ingest_apple_jws` remains fail-closed (line 430). A real path needs an agreed trusted endpoint and authenticated player/account-binding issuance, production verifier/notification source, and server authority over current entitlements/refunds. Without an endpoint/auth contract, credentials or signed live transactions, a local transport stub would only repeat the already-tested fixture path. Do not enable production purchase UI or grant rights from R454/R461 mock outputs.

**External/product gates:** actual App Store Connect product IDs, prices/territories/quantities, server key custody and deployment, Apple sandbox or production account validation, device testing, operational monitoring/backup/abuse controls, and legal/platform review. These are not evidenced by local builds or mock credentials and should remain explicit release gates.

**No additional test recommended now.** Resume local integration only after the service owner supplies the endpoint/authentication and product contract; then test the real verifier/client wiring against that contract, retaining the existing local suite as regression coverage.
