# R465 search-clear runtime helper

Preparation only. This helper is not run and does not launch the Simulator app automatically. Root must seal the actual R465 Release build receipt and current R462 closed-runtime pins in `RUNTIME_SEAL_R001.json` before invoking it.

The fixed install target is a new `local.witch.autonomous.r1.completion.r465` namespace on Simulator 9A. The helper refuses an existing R465 install/data container, copies exactly the three R456 revision-138 seed files into the fresh R465 support directory, and protects the exact R445/R454/R456 trees plus both R462 app and data trees. It revalidates those trees at each checkpoint and finish. R462 app bytes are checked against its closed Release receipt; R462 save files are checked against its closed cold checkpoint. The R462 app/data paths and run/build receipt hashes are fixed to the closed source run.

Use the five checkpoints in order: `home`, `empty_search`, `filters_cleared`, `before_cold`, `cold`. Only the first three and final `cold` take screenshots (four total); `before_cold` records save/process state only. Root performs the UI actions and judges pixels/accessibility separately. The expected visual observations are that clearing the IME search leaves the accessibility search value empty and all 43 quality-filtered items visible, then returning focus does not restore the prior search text. The helper records images and exact save bytes; it does not infer those UI results from screenshots.

The primary and previous save bytes must remain exactly equal to the revision-138 R456 seed through all checkpoints and after a cold relaunch with a different process identity. The auxiliary identity file may legitimately be rewritten by each bundle launch, so R462 is checked against its own cold identity-file hash while R465 captures its own value; it is not falsely required to equal the R456 identity bytes. This is a narrow search/filter persistence capture, not a gameplay acceptance or product-quality approval. Bounds remain 600 seconds, 1.04 GB total added storage, at least 15 GB free at start and 10 GB throughout, four screenshots at 20 MB each and 40 MB total evidence. No video, save editing, deletion, automatic launch, purchase, or clock injection is used.
