今回の主要検証は、R461のPython10件とSwift37件、R463のSwift45件（既存37+追加8）、別7プロセスによる再起動/同時更新/返金保持で合格した。件数は重複する回帰試験を含み、合計した独立要件数ではない。課金権限は本番無効のままである。R463の256操作上限は隔離検証の累積上限で、実運用の保持設計ではない。

R462では検索解除後に日本語IMEの文字だけ残る不具合を実画面で発見した。R465でフォーカス解除と入力欄の再生成を実装し、空欄、品質「すべて」、43件への復帰、再入力、未確定入力の解除、冷起動を確認した。R462の失敗は保全し、後の成功で書き換えていない。初回の試験/事前検査失敗も保存済みである。

最新R465ビルドは274.385秒、割当1.442GB。既存1,922資源をAPFSコピーで再利用し、完全コピーへのフォールバックは0。旧製品15,400ファイルと、実行時の旧8アプリ/データツリー7,776ファイルを照合した。実画面試験は222.780秒、保存画像4枚約4.2MB。空き容量は約131.7GB。未承認削除は行っていない。

残作業は次の優先順位で管理する。

1. **ゲームの成立を阻む問題**：固定版監査で再現した保存破損・進行不能・クラッシュを最優先する。3分野の固定SHA監査では確認範囲に再現P0/P1なし。
2. **発売品質を阻む問題**：本番サービス/アカウント連携/商品条件を確定した後、実ネットワーク・正式課金・通知/再送・保持/復旧を実装し、実Apple Sandboxで検証する。Apple認証、実機導入と操作、正式仕様/美術/商品採用はHumanの操作または決定が必要。ローカルmock試験で代替しない。
3. **細部の改善**：再現する操作性/視認性障害だけを対象に、原則1件2試行/15分。根拠のない原画再制作や数ピクセルの反復調整を続けない。
