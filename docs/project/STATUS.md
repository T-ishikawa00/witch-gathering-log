## 再開時の優先事項

1. 本人が残すゲーム体験上の問題を具体化し、修正対象と採否を決める。
2. 固定資材パックと原画・編集元の独立バックアップ、権利根拠を確保する。
3. 対象機種・OS・ビルド識別を伴う実機確認、保存・復旧・長時間動作を行う。
4. 正式な課金方針、商品仕様、購入検証基盤、引継ぎ方針を決める。
5. リリース条件を本人が判断する。整備作業から公開・販売を自動実行しない。

既知の技術制約：原画・編集元と固定runtime packの全量はmainに含めていない。資材組立の再生成経路は完全なGit-only手順ではない。Coreの長期経済・購入host fixtureの試験には明示の追加入力が必要。新しいtoolchainでの警告はビルドログに残す。
