# 判断と実行範囲

## 既存方針を維持

4人完全自動、手動技能/作戦設定なし。既存5地域と159アート制作単位、標準容姿、UI Aの美術方向は変更しない。
R6-Bは最新の参照候補、ガチャCは試遊候補のまま。今回のテストPASSは正式採用の代わりではない。

## 今回だけの明示的な接続案

1. 33型版を検証するため、既存Commerce29型へ猫4型のメタデータを、人型の対応部位から追加。能力と費用は成長R2を参照する。既存世界29型は置換しない。
2. CommerceのAF_BARRIERを入力変換上だけAF_WARDへ対応させる。5〜10％/barrier_bonus_bpを数値側の候補正本とする。既存保存値の一括置換ではない。
3. ガチャの「合法範囲上半分」をR2の0..1000へ写像。伝説のraw qは800..1000、その他は500..1000。潜在3枠を一度だけ生成し、先頭に取得時の用途保証を置く。
4. 操作モデルは非表示潜在値や未来の戦闘を見ず、公開された数値が非減少の同型更新/空き部位への装備と、固定順の強化を行う。これはユーザー用の自動装備/自動消費機能を追加する決定ではない。
5. FULL群は保護後の低品質候補を本人が確認して処分する仮定。潜在価値まで含む不要判定ではない。実ユーザーが候補を保留すれば得る粉は変わる。

## 今回決めていないこと

ガチャの実解放時期/価格/無料券/実課金、追加副効果プールの広さ、潜在枠の公開方法、猫4型の正式アート制作、全33型の戦闘、返金/複数端末/保存移行、衣装家具の共鳴、全画面のUI。

## 今回の主比較の読み方

- 各条件は24組の自然装備・制作・ガチャ乱数×8戦闘乱数。共有した初期条件/乱数を使うので独立した192人の標本ではない。
- 元のR6試験は比較のために自然装備を未使用にしていた。本試験は開封前に自然装備と手持ち粉を使う。同時に操作手順も違うので、「自然装備だけで差が生じた」と限定しない。
- FRESH4はG_R01_A後に4人加入済み・森深部確認済みという初期状態。実際のガチャ導入タイミングを確定したものではない。
- 保証は空から。5回無料は一度受け取ったバッチで、無料供給の時計実装ではない。
- 敵は元R5/R6のredistribute_pause候補。遅い結果を出すために後から敵を強化していない。
- 6時間/12時間は有効な採集時間であって、必須の足止めやユーザー所要時間ではない。
- 生成品が高品質でも基礎能力は品質で乗算しない。原R2の型・研成・強化が基礎値、副効果が品質差を作る。
- 新しい低品質装備の処分以外に、既存装備や投資済み個体を勝手に処分しない。初回品、ロック、装備、セット参照、人数分の控えを保護する。

## 実行後に見つかったこと

C50は初回の空き部位を埋めて攻略を大幅に前倒しする。準備済みの無料対照もこの参照ボスに勝てる。一般的な購入価値の証明でも、ガチャが必須だという結果でもない。
ガチャの狭い追加副効果プールと、潜在3枠がある装備をどう整理するかが、次の仕様上の論点。

同じ原本と条件から得た不都合な結果も保全する。旧R6-A/Bや旧ガチャ案Aの資料を削除せず、Cの確率を今回の成績に合わせて無告知で変更しない。
