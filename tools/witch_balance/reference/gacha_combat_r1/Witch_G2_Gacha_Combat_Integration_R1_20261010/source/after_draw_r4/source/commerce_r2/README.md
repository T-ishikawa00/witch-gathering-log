# 魔女の採集帳 — ガチャ商品・恒常効果・制作規格 詳細設計R2

**入口：READABLE_DESIGN.html**（今回の設計書。ゲームUI試作ではありません）。全文は `docs/DESIGN_R2.md`。

3%/40回/80回、150円、共鳴上限3ポイント、追加衣装4/家具10等は今回の**未承認提案値**です。旧R2/R3の確定値として扱わず、発売許可に読み替えないでください。

## ファイル構成

- `data/`：候補数値、29装備の出典付きメタデータ抜粋、新しい副効果対応案、製品候補、制作契約、判断/課題台帳。
- `tools/`：決定的な模擬抽選・所有権・数式・契約チェックと74テスト。
- `results/`：実行した新74テスト・前回46テスト・5万抽選系列の照合・確率計算。
- `source/`：前回レビューZIP、方針メモ、A/B比較画像をバイト列のまま保全。画像は左2画面のA方向のみ採用済み。
- `handoff/`：後日の保存・照合用。実行の許可は別。

**旧戦闘R1〜R6統合ZIPは含みません。** 現在の環境にないため、旧バランスランナーを再構成して正本化していません。原本回収後に実際のR6へ接続する必要があります。

## 再現

Python標準ライブラリのみ。コードを確認し、展開フォルダで以下を実行。

```sh
python3 -B tools/verify_package.py
python3 -B -m unittest discover -s tools -p 'test_commerce.py' -v
python3 -B tools/run_analysis.py --output ./rerun/analysis.json
```

抽選は模擬RNG、購入は模擬の検証済みフラグ、保存はメモリ内差替えです。実課金・セキュリティ・DB電源断・R6戦闘・実機・新しいアートは未検証。
