# 魔女の採集帳 — 装備ガチャ・着せ替え・家具 方針メモ R1

作成日: 2026-10-10
状態: ユーザーの希望の記録＋設計提案。ゲーム数値、商品価格、排出確率、制作数量、実装範囲の最終承認ではない。

## 1. 今回のユーザー発言から確認できること

- 想定しているガチャの主対象は新キャラクターではなく装備。強くなること、高レアを集めること、格好よさ・可愛さを収集することを重視する。
- 欲しい衣装を直接購入し、キャラクターの着せ替えをゲーム内へ反映する構想を希望する。
- 家を高品質にカスタマイズできるなら、家具・衣装にも価値を感じる。
- 家具・衣装が可愛いだけでなく、恒常的な能力効果を持つ案にも関心がある。具体的方式・効果量の採用は未決。
- 既に選ばれたUI A案「暮らしが見える家」の方向性を維持する。既存4人と標準衣装の正本は置換しない。

## 2. これまでの方針を維持する範囲

- 4人が育成・戦闘参加する完全自動戦闘。作戦プリセット、AI条件編集、手動スキルを再導入しない。
- 下部の入口は「家・探索・仲間・工房・採集帳」の5つを基準とする。
- 新しい課金の話を、キャラクターガチャやPvPの導入許可に読み替えない。
- 成長R2・経済R3・支援AI R6等は既存案/検証として保持。有料ガチャ、家具、衣装の能力効果を加えたバランスの合格証拠にはならない。
- 自然ドロップの確率・保証をそのまま有料ガチャへ転用しない。

## 3. 今回の推奨設計（未承認）

### 商品の役割

- 装備ガチャ: 装備収集と戦闘の変化を中心とする収益候補。家具・衣装を混ぜて装備狙いの外れにしない。
- 衣装: 単品を選択して確定購入・恒久解放。購入前に家、仲間画面、戦闘の実表示を試着確認できる構想。
- 家具/内装: 家具単品または内容が分かるテーマセットを確定販売する構想。無料の採集・制作でも家が育つ導線を別途設計する。
- 広告省略等: 補助商品候補として保持。購入需要や売上は未検証。

### 見た目と能力の分離

- 戦闘装備の個体/能力、見た目に選ぶ衣装、家具の配置を別の保存情報にする。
- 衣装/家具の効果を採用する場合、着用/展示を必須にせず、所有に紐づく補助効果案を比較する。
- 同一品の重複で無限加算しない。合算上限と通常プレイ側の育成経路を設計する。
- 有料の能力効果があれば、純粋な見た目商品とは説明しない。
- 特定の有料ランダム品を揃えると別報酬が得られる設計を安易に追加しない。組合せ要件は個別の法的確認対象。

### 制作方式

- A案の家は、背景・家具・4人・前景/遮蔽・UIを分離する。完成合成一枚絵をそのまま着せ替え対応と称しない。
- 初期候補は全身衣装セット単位。帽子/服/靴の任意組合せを最初から全保証しない。
- 衣装は家、仲間全身表示、戦闘で共通の選択を参照する設計案。反映範囲を明示し、売り場のイラストだけ変わる商品にしない。
- 家具は位置/カテゴリを規格化した配置方式を第一候補とし、窓/暖炉/照明/ラグ/机などの入替と仲間の動作を両立させる。
- 正確な衣装数、家具数、価格、排出率、能力上限は未定。既存159地域アセット単位とは別の追加スコープ。

## 5. 購入設計の検討事項

- 本案ではStoreKitの消耗型/非消耗型の違いを踏まえ、衣装の恒久解放は非消耗型商品を第一候補にする。
- 有料ランダムアイテムは購入前の確率表示を組み込む。価格、保証、重複処理、排出範囲を明記する。
- 購入権の復元と、消費済み券・抽選結果・装備個体の復元は別問題。二重付与、通信断、返金、機種変更、オフライン境界を設計する。
- 検討する構成は通常の探索/戦闘をオフライン、購入/有料抽選/所持権同期をオンラインに分離する案。サーバー構成は未決。
