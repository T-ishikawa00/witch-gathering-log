## 読む順序

`READABLE_REPORT.html`（または `REPORT_R4.md`）→ `review/AFTER_DRAW_REVIEW.html`（固定結果の操作試験）→ `results/VALIDATION_SUMMARY_R4.json`。

操作見本はブラウザで開ける単独HTMLです。実課金・外部通信・Macのゲーム保存を行いません。既存のUI A案の描き直しではありません。結果の読み取り・保護・まとめ処理・強化への戻りを確認するためのものです。

## 主要な発見

1,500円相当のC50個は、9基本型の比較条件で約20〜31個を保留し、普通1粉/良質2粉なら約30〜42粉を回収できました。既存の低品質の控えや共用品の保護数で変わります。保留品を装備更新や戦闘強化の実績とは呼びません。

「希少以上を全て保留」のままでは自然探索だけでも在庫が増えます。まとめ処理は全件厳選の完了と異なります。人の整理秒数は未測定で、仮定時間と自動操作の時間を分けています。

## 検証範囲

主比較14,000条件/378,000個、同じ結果を使うQ2重複整理の8,000条件、目標別6,000条件/180,000個、主比較後の在庫感度6,000条件/180,000個。乱数や初期状態を共有した比較なので人数や全件独立試行に読み替えません。

新契約62テスト、旧R3の30・旧CommerceR2の74テストを実行。Chromiumで3寸法/12動線/170チェックポイントと40反復の自動操作計時を実施しました。人間・実機・実R6戦闘・完全な素材経済・StoreKit・返金の検査ではありません。
