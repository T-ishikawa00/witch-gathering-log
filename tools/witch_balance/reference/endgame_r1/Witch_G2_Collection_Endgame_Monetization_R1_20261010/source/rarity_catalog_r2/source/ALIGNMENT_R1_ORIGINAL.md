## 4. 今回からの商品設計方針案

支出額と購入目的の二軸で設計する。

支出額: 無購入/少額単発/少額継続/高額購入。実際の金額境界は未定。
購入目的: 快適性/装備収集・強化/衣装/家・家具/割安なまとめ購入。

固定した身分・VIP条件として表示する方針ではない。
同じ人が複数目的を持つ場合、一度だけ広告省略を買う場合も分ける。

各商品の設計表に記す項目:
- 主な想定層と購入目的
- 内容と反映範囲
- 価格候補、券数量、無料分・有料分の区別
- 買い切り/消耗型/期間型、購入上限・更新条件
- 進行・素材・所持数・保証カウンターへの影響
- 重複、既所有品、復元、返金時の取り扱い
- 単品とパックの比較条件、誤認を招かない割引の根拠

提案原則:
- 広告省略だけ買える経路と衣装単品を残す。不要なガチャとの抱合せだけにしない。
- 無課金かつ広告なしの体験も基準ケースにする。
- 同じガチャで購入者の支出層によって確率・保証を裏で変えない。
- 高額購入層向けは収集の幅・速度・選択肢も評価し、無制限の所持バフへ置換しない。
- 広告を導入する場合、広告省略が消す対象と報酬の受領条件を商品ごとに明示する。
- 月額/パスは比較候補であり、サービス運営・定期商品追加の正式決定ではない。

## 5. 次回検証の順序

1. 品質が性能・見た目・昇格へ与える役割を確認する。
2. 支出層×購入目的に沿った商品カタログ案を作る。
3. 無料配布、広告、広告省略、小額パックを合算し、ガチャ解放時期と初期供給を設定する。
4. 潜在副効果の確認と、保護・一括整理の範囲を確定する。
5. 同じ進行条件で30日/90日を比較する。

比較ケース案:
無購入・広告なし/無購入・任意広告あり/広告省略のみ/衣装・家具のみ/
少量ガチャ/お得パック中心/継続少額/高額ガチャ中心/高額衣装・家具中心。

全員の支出をガチャ券へ換算しない。割引パックの購入回数制限・時期も反映する。
広告省略や外観商品の恒常効果を採用する場合は、その影響も分離計測する。
