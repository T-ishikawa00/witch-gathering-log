# レポート表示の確認

ChromiumにHTML文字列を読み込み、1280×900と390×844の2条件で描画。file://での直接ナビゲーションは環境制限により利用できず、set_contentで確認した。

初回のモバイル確認では参照パスの長い文字列が折り返されず幅730pxになった。本文全体の折返しを追加し、再確認でdocument.scrollWidth=390px。テーブルは表内の横スクロールを許可する。外部HTTP要求なし、JavaScriptエラーなし。

スクリーンショットの目視確認を含むが、リンクをすべてブラウザ操作した検証でもiPhone/Safari/ネイティブUI試験でもない。
