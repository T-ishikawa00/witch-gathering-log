# 原本の収録範囲

source/の55ファイルは前回の品質昇格・導入・経済R1 ZIP内のsource/をそのまま取り出した部分コピー。今回必要な計算依存とデータ・一部報告を含む。

古いPACKAGE_MANIFEST.jsonやSOURCE_LOCK等は元パッケージの履歴であり、この部分コピーを全体へ拡張する証明ではない。今回の実在一覧はdata/SOURCE_LOCK.jsonとルートPACKAGE_MANIFEST.jsonで確認する。

元の品質昇格・導入・経済R1 ZIPはhistory/へ同一バイトで収録。このZIPに含まれない、さらに古い全資料や原画の完全アーカイブを今回新しく作ったわけではない。

計算の再実行はtools/から新規出力先へ行う。source/内のデータを修正して新しい案を試さない。新条件は別設定で保持する。

今回のブラウザQA画像はこの検証レポートの読取り用であり、採用済みUI A案に代わるゲーム画面ではない。
